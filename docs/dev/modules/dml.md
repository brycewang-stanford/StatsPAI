# 双重机器学习

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`dml/`**：`sp.dml(model=...)` 是截面 DML 的 dispatcher（plr / irm / pliv / iivm）；面板另开两个函数，不进 dispatcher（签名要 unit/time）。`sp.dml_panel` 是带单位 FE 的静态 PLR；**`sp.dynamic_dml`（1.31.0）是时变处理的序列效应**（Lewis & Syrgkanis 2021）——处理会改变后续状态时，静态估计量不是低效而是错的。三角矩条件按**堆叠 GMM** 一次解出，点估计与倒推一致但附带跨期联合协方差（总效应 se 0.032 对独立相加 0.062）。给定相同的折与一阶段学习器，与 `econml.panel.dml.DynamicDML`（方法作者写的参考实现）在点估计**和** SE 上都对到 1e-15，是 T2。`lags=1` 是默认且不可省：状态里没有处理史时估计量不是变噪声而是**自信地错**（三期偏 −15% / −15% / +37%，无一覆盖真值）。
- **`dml/did.py`（`sp.dml_did`，1.39 起）**：两期 DML-DiD，面板（ΔY 或长表 `time=` + `id=`）与重复截面两种布局，不进 `sp.dml` dispatcher（签名不同）。canonical 参考是 Python `DoubleML` 的 `DoubleMLDID` / `DoubleMLDIDCS`：同折、同学习器下点估计与 SE 对到 1e-15（`test_dml_did_doubleml_parity.py`，夹具只收确定性学习器，森林版依赖 sklearn 版本）。处理组份额用**全样本**均值（DoubleML 的做法）；教材和 Chang (2020) 按训练折估，`in_sample_normalization=False` 时份额在估计量里约掉。倾向得分是截断不是删行，截断数进 `model_info` 并告警。**已知真值测试不要用随机森林当学习器**：二次趋势设计上 n=600 时森林的冗余参数偏差让估计停在 2.69（真值 2），n=20,000 仍有 2.12，这是学习器的收敛速度，不是估计量的 bug。
- **`sp.dml(design=)`**：`design=`（复杂抽样设计，2026-10-19 起）只有一个方差入口：`survey/linearization.py::design_vcov`（= R `survey::svyrecvar`，含 strata / PSU / fpc / lonely-PSU / 校准），估计器只负责交出逐行贡献 `u_i`（`theta_hat - theta ≈ Σ u_i`，抽样权重已在里面；对均值归一的权重就是 `u/n`）。不要在估计器里再写一份 PSU 求和或 `G/(G-1)`。`design=None` 时代码路径与之前逐位相同；`design=` 与 `weights=` / `cluster=` / bootstrap 同用一律报 `MethodIncompatibility`。推断用 t(#PSU − #strata)（Stata `svy` 口径）。证据在 `tests/reference_parity/test_survey_causal_parity.py` / `test_survey_did_parity.py`（R survey 4.5，1e-14 量级）。 交叉拟合的折按整个 PSU 划分（复用 `cluster=` 的分折，但估计量是普通加权 DML2 解，不是 `_cluster_theta_se` 的折加权解）；方差把交叉拟合的冗余视为已知。多处理 PLR、`store_oof`、`external_predictions` 拒绝。
- **两向聚类 DML（`sp.dml(cluster=[c1, c2])`，2026-10-19）**：照 Python DoubleML 0.11.3（BSD-3，可读源码）`DoubleMLClusterResampling` / `_var_est` 的定义，在 `_base.py::_twoway_splits` / `_twoway_theta_se` 独立实现：每个维度各分 K 折，K² 个格子，格子 (k, l) 的训练集是两个维度都**不在**测试折里的单位（与测试格共享任一聚类的单位被排除在训练外，不是只排除测试格本身）；估计量按 `1/(|I_k||J_l|)` 加权，方差 `Gamma` 的常数是 `min(|I_k|,|J_l|)/(|I_k||J_l|)^2`，最后除以 `min(G1, G2)`。给定同一组折（`fold_indices` 为 n×2）与 DoubleML 对到 1e-15（T2）。没有给折时两维各自用 `KFold(random_state=seed + 7919 j)`，与 DoubleML 的随机划分不同，所以只有给定折时可比。灵敏度界（`sp.dml_sensitivity`）在两向聚类下不带抽样误差。`design=` 与两向聚类不同时用。
- **2026-11-13 机器学习因果盲测（probe-ml）留下的约定**：(1) `sp.dml_sensitivity(benchmark_covariates=)` 的基准是**重拟合**：去掉基准协变量，在同样的行、同样的折（种子 / 用户折 / 聚类折）和同样的学习器上重跑同一个模型，再按 Python DoubleML 0.11.4（BSD-3，可读源码）`gain_statistics` 的定义算 `cf_y` / `cf_d` / `rho` / `delta_theta`（`dml/_benchmark.py`，401(k) 与 Lalonde 上对到 1e-13）。1.43.1 及以前用「协变量与交叉拟合残差的相关系数平方」，协变量本来就在冗余回归里，这个数按构造为零，**不要改回去**。重拟合靠 `model_info['_benchmark_refit']`（`ShortRefit`：估计器对象 + 完整行）；带 `sample_weight` / `design=` / 双向聚类 / `external_predictions` 的拟合没有它，基准请求直接报 `MethodIncompatibility`，未知协变量名也报错（以前静默跳过）。`ShortRefit.__repr__` 是固定文本，因为 `to_dict()` 会把不能编码的对象转成字符串，默认 repr 带内存地址。(2) IIVM 的一阶段概率 `r0` / `r1` 只截到 [0, 1]：它们不在分母里，以前的 1e-4 内截断会把单边不依从（`Z=0` 时无人受处理，`r0` 恰为 0）的估计推离 DoubleML `subgroups={'always_takers': False}` 的结果（401(k) 上相对 4e-6）。(3) `score='ATTE'` 的结果 `estimand` 是 `"ATT"`。(4) `sp.dml` 的 `**kwargs`：`seed=` 是 `random_state=` 的别名；未知选项仍是 `TypeError`，但报文给出最像的合法名字和全部选项（`_article_aliases._check_dml_options`，常见外来拼写在 `_DML_OPTION_HINTS`）。(5) 已核对、不是缺陷的差异：边界标准误与 DoubleML 上下互换（见上，有限差分测试）；RV 我们是闭式解，DoubleML 的求根器差 7e-6；`sp.metalearner(learner='dr')` 的结果模型按臂分别拟合，econml `DRLearner` 把处理当作一个回归元合并拟合，CATE 不同是约定不同；grf 的不同种子给出几乎相同的森林（401(k) 上每个种子深度 1 的分裂计数都是 64/222/90/15…），所以它的跨种子标准差低估森林噪声，我们的跨种子标准差是独立树应有的量级，不要拿 grf 的种子离散度当目标。
- **`sp.dml_sensitivity(rho=, level=)`（2026-11-13）**：`rho` 乘在置信强度上（`|rho| sqrt(cf_y cf_d / (1 - cf_d))`），稳健值在该 `rho` 下求；`level` 换的是区间的单侧分位数。默认 `rho=1.0`、`level=1-alpha` 与此前逐位相同。对 doubleml 0.11.4：界与其标准误 1e-10（标准误仍是交叉对应），稳健值在其求根器容差内（绝对 1.3e-6）。
