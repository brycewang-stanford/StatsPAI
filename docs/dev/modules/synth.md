# 合成控制

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`synth/`**：20+ 估计器全部经 `sp.synth(method=...)` 分发。新增方法要同时加到 dispatcher 和 `synth_compare()`。`method='classic'` 的 `ci` 是与安慰剂秩检验 p 值对偶的常数效应反演区间（`_core.placebo_inversion_ci`，Firpo-Possebom 2018；供体少于 `1/alpha - 1` 个时为 `(-inf, inf)`），旧的 `estimate ± z·sd(placebo ATT)` 只留在 `model_info['ci_normal']`——**不要**再让 p 值和区间出自两套程序（2026-10 Gaillac-L'Hour 教材第 10 章查出）。
- **`synth/_gsynth_multi.py`（`sp.gsynth(treat=)`，1.39 起）**：多处理单位、交错处理、带协变量的广义合成控制（Xu 2017）。对照组上的 IFE 是「β 的最小二乘」与「残差矩阵双向去均值后截断到秩 r」的交替最小二乘；固定 r 时与 R `gsynth` 对到 1e-12（r = 0..3、有无协变量、交错）。`covariates=` 的调用（含单处理单位）一律走这条路径：旧的 `_partial_out_covariates` 是不含截距和固定效应的混合 OLS，书中数据上 6.68 对 5.70，已在 1.39 记 ⚠️。因子数用论文的留一处理前期准则；`gsynth` 1.4 转调 `fect`，交叉验证方案不同，**不要声称选 r 的规则与 R 一致**。无协变量的单处理单位路径（Track A 19 号模块）没有动，它的选 r 规则是随机遮盖对照矩阵的单元格，与两者都不同，改它会动冻结产物。gsynth / fect 是 MIT。
- **`synth/_multisynth_qp.py`（`sp.staggered_synth` 的权重 QP，2026-10-19 起）**：不再形成稠密 Hessian。Hessian 是「按处理单位分块的块对角 + 秩为 `n_lags` 的合并项」，自由集上的 KKT 按块解、合并项用 `n_lags × n_lags` 的 Schur 补并回，块的分解只在它的自由集变化时重算；迭代规则（顶点起步、比值检验、入基规则、容差）与旧的稠密 active-set 相同，所以解相同到舍入。`nu → 1` 时块自身曲率可忽略，Schur 结果先用驻点残差核验，不过就退回稠密 KKT。`nu = 1` 且无 ridge 时最优解不唯一，只保证目标值。
- **`synth/augsynth.py`（`sp.augsynth`，2026-10-19 起）**：跟 R `augsynth` 0.2.0 的 `single_augsynth`。多个处理单位共用一个处理时点时取平均轨迹当作一个处理单位（R 的 `colMeans`），处理时点不同时拒绝并指向 `sp.staggered_synth`（multisynth）——**不要**在这里自己实现 multisynth。`progfunc` 只原生实现 `ridge` / `none`，其余（EN 的 glmnet 交叉验证有随机折、GSYN / MCP 需要别的包）一律 `MethodIncompatibility`。协变量走 R 默认的 `residualize = FALSE`：按处理前均值聚合、以对照均值中心化、缩放到 `sd(X_c)`（中心化对照结果矩阵**全部元素**的标准差）后拼到结果列上；CV 的留出列也会落到协变量列上，这是 R `get_lambda_errors` 的原样行为，跟着它。R 桥（`_augsynth_r.py`）只跑单处理单位的 Ridge。Track A 18 号模块的路径没变，结果逐位复现。
- **`sp.sdid` 的两个入口（2026-10-19 起）**：`treated_unit=` / `treatment_time=` 带 `covariates=` 或 `se_method='noinference'` 时，构造「处理单位且 `time >= treatment_time`」的 0/1 列交给 `treat=` 路径（`_sdid_block_via_treat`）。两个入口在无协变量时点估计与 jackknife SE 都一致到 1e-15，所以不要再给 `treated_unit=` 单独写一套协变量实现。Track A 12 号模块（无协变量、placebo）不经过这条分支。
- **`synth/_fect_tests.py`（`sp.fect` 的 placebo / carryover / loo 检验，2026-10-19 起）**：跟 R `fect` 2.4.1。相对期用 fect 编码（0 = 最后一个未处理期；关闭后 1 = 第一个未处理期），所以 `placebo_period` 要 `<= 0`、`carryover_period` 要 `>= 1`。检验只在设了 `vce` 时可用，一次只做一个。**F 检验与 fect 有一处有意的偏离**：`fect:::diagtest` 在 `vartype = "jackknife"` 时用原始留一复制值的 `cov()`，比 jackknife 协方差小 `(n-1)^2/n` 倍，F 因而大同样倍数、平行趋势被错误拒绝；我们用 jackknife 协方差，测试钉住 `F_fect = F * (n-1)^2/n` 这条恒等式（T4 有机制的约定差异，不是 parity）。fect 的 loo 在 jackknife 下要 `nboots = N`，否则 R 侧报错。bootstrap 路径两边都是 `sd` + 正态近似，随机流不同，只能当筛查。
- **`synth/_scest_multi.py`（`sp.scest(treat=)`，2026-10-20 起）**：多个处理单位、交错采纳的 scpi 点估计。每个处理单位单独解一个单位问题（就是单处理单位的 `sp.scest`，约束集按单位可分，所以联合问题等于逐单位求解），处理前窗口是采纳期减 `anticipation` 之前的各期，供体只用**从未处理**的单位（较晚处理的单位不作供体，`treated_unit=` 只选一部分时被排除的处理单位也不作供体）；`effect='time'` 只报告所有处理单位都到达的视界 `1..min_i T1_i`。这是**净室实现**：只依据 R `scpi` 帮助页与 R 的黑箱输出（`scpi` 是 GPL-3，**不得**读其源码；本地分支 `wt/feat-synth-family` 上读过 GPL 源码写的 b7c85f1a 已删除，不要找回）。证据是 R 输出等于"用 R 的权重走同一构造"（1e-12），R 的权重在其求解器 1e-8 的对偶间隙内（强凸性给出权重距离上界），`ols` / `lasso` 权重 1e-9。推断（`sp.scpi` 的多单位预测区间）没有做。
- **`synth/scpi.py` + `_scpi_inference.py` / `_scpi_insample.py` / `_scpi_simulate.py` / `_scpi_qp.py` / `_scpi_solvers.py`（`sp.scdata` / `sp.scest` / `sp.scpi`，2026-10-20 净室重写）**：审计 H1 指出旧代码自称移植 R `scpi`（GPL-3），已整体删除重写。依据只有两篇论文（`cattaneo2021prediction`、`cattaneo2025scpi`）、交错采纳论文及其附录、R 帮助页、仓库测试与 fixture、以及把 R `scpi` 当黑箱跑出的输出；规格与每条约定的黑箱证据在 `docs/dev/cleanroom/scpi.md`。**不得**读 `scpi` / `scpi-pkg` / `Qtools` / `quantreg` / `CVXR` / `ECOSolveR` 源码（都是 GPL）。论文没定、只能从黑箱读出的约定：ridge 半径在 `T0 - J <= 10` 时先用 L1 球拟合筛供体（至多 `max(T0-10, 2)` 个），`T0 < 5` 时 R 不报 `lambda`（`sp.scpi` 拒绝并要求 `Q=`）；rho 的 `sigma_u` 用总体标准差、`sigma_b` 用样本标准差，数据驱动的 rho 低于 1e-3 改用 `rho_max`；模拟约束集里 lasso 的半径在 `||w||_1 > Q - rho` 时取 `||w||_1 + rho`；ridge 的 L2 球在 `||w||_2^2 > Q - rho` 时取 `||w||_2^2 + rho`（R 拿平方范数和 Q 比，黑箱逐条确认，不是笔误），L1-L2 的 L2 球用同一规则但 rho 取 `min(rho, rho_max)`；HC2–HC4 的杠杆是 `B`（全部供体）的帽子矩阵；`e.var = min(对数平方残差回归的预测, (IQR / 1.34)^2)`，IQR 一律来自受限回归分位数（He 1997），只有常数设计下的 `qreg` 区间用 type-7 样本分位数；联合区间 = 各期极值的分位数 + `sqrt(log(T1 + 1))` 乘次高斯样本外区间。这些约定由 `tests/reference_parity/test_scpi_cleanroom_parity.py`（17 个配置、三个合成面板）钉住。样本内问题的求解：主动集（工作面上的闭式解，带球时是两个二次约束的比值根），不收敛时先用 SLSQP 猜工作面再闭式抛光并核验 KKT，再不行用对偶法（凸二次约束的拉格朗日对偶 + 精确 QP），最后才是 SLSQP（计入 `n_slsqp_fallback`）。
