# 回归族（似然模型、GEE、GAM、选择、非参数树）

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`regression/mprobit.py`**（`sp.mprobit`）：选择概率是按 GHK 的逐维条件形式写出、再用 Gauss-Legendre 求积积分的（备选项 ≤ 4），**不是模拟**。求积节点做了 `u = s^3(10 - 15s + 6s^2)` 的变量代换，不要拿掉：被积函数经过正态分位数函数，在单位区间两端导数无界，朴素的 Gauss 规则只有 O(m^-2) 的收敛（24 个节点误差 2e-4，代换后 5e-8），对数似然会差 0.1。导数是先对效用求差分再乘设计矩阵，不要退回对每个系数做差分（慢 4 倍以上）。归一化与 Stata `cmmprobit` 相同：与基准相减后的误差协方差，scale 备选项的方差为 2。证据：对 Stata `mprobit`（同样是求积）T2；对 `cmmprobit`（模拟）只能到 3–4 位，回放里按「系数在 Stata 标准误的 2% 以内」判定，不要写成严格对齐。
- **`nonparametric/conditional_tree.py`（`sp.ctree`，2026-10-12 起，来自 Varian 2014 的复现）**：条件推断树（Hothorn-Hornik-Zeileis 2006）。`party` / `partykit` 是 GPL，**只当黑盒，不读源码**；论文没写明、靠输出反推的三条约定各有夹具守着：(1) Bonferroni 的 m 是**本节点内取值不恒定**的协变量个数（被上层切分用尽的变量不再计入）；(2) 子节点至少 `max(min_bucket, ceil(min_prob * n))` 个观测，选中的变量没有可行切点时换下一个显著的变量；(3) 无序分类变量的左子集含节点内出现的第一个水平，节点按 partykit 的先左后右深度优先编号。p 值下溢时按 `chi2.logsf` 排序，不要改回比较 p 值本身（工资数据根节点有两个变量 p 都是 0）。树是确定性的，证据是 12 组设置上与 `partykit::ctree` 逐节点一致（T2）；重生夹具先跑 `_generate_ctree_data.py` 再跑 `_generate_ctree.R`（`R_LIBS=~/.statspai-rlib-ctree`）。只做了二次型检验统计量；最大型统计量要多元正态概率，蒙特卡洛 p 值是随机的，都没做，**不要**凭印象补。模块叫 `conditional_tree.py`，不要改成 `ctree.py`（与函数同名）。同一轮修了 `sp.lasso_select(method='cv')`：各训练折必须用自己的行重新中心化和标准化、带自己的截距，误差按观测合并；`tests/test_lasso_select.py` 断言同折同惩罚下它的 CV 曲线等于 `sp.glmnet` 的。小样本上 CV 曲线可以是双峰的（增长数据上 `cv.glmnet` 40 个种子里 λ 要么约 0.005、要么约 0.17），单个种子选出的变量名单不构成证据。
- **`selection/elastic_net.py`（`sp.glmnet`，1.39 起）**：glmnet 口径的 lasso / ridge / elastic net（gaussian、binomial），与 R `glmnet` 4.1-10 的路径对到 1e-10、系数 1e-6、`lambda.min` / `lambda.1se` 同一格点。glmnet 是 GPL，**只当黑盒，不读源码**；文档没写明、靠输出反推并各有一条测试的四个约定，改之前先看 `test_glmnet_r_parity.py`：(1) gaussian 的 y 先标准化到单位方差，所以原尺度下岭惩罚是 `lambda / sd(y)`；(2) 自动路径的首点是无穷大惩罚下的拟合（岭回归时系数约 1e-36，不是标签上那个 λ 的解）；(3) 自动路径提前停止，gaussian 按相对增益、binomial 按绝对增益，阈值 1e-5；(4) `cv.glmnet` 的每个训练折**自建路径**，再按 λ 线性插值到全样本的 λ 上（给定 `lambda_` 时才在这些 λ 上直接拟合）。收敛阈值比 glmnet 默认严得多；p > n 且 λ 接近 0 时 glmnet 自己没收敛（差 1e-3），那里的证据是次梯度条件，不是对 R。与 `sp.shrinkage` 并存：后者的惩罚写在 RSS 上、用 n−1 标准差，换算式在指南里。坐标下降是纯 NumPy，**不要**为提速引入 numba 的非惰性 import。
- **共线回归元（`core/_collinear.py`，2026-10 起）**：`sp.logit` / `probit` / `cloglog` / `glm` / `poisson` / `nbreg` / `ologit` / `oprobit` / `mlogit` / `tobit` / `qreg` / `svyglm` 在拟合前调用 `drop_collinear`（按列名建模的用 `drop_collinear_names`），按公式书写顺序扫描、常数项最先、剔除相关集里靠后的那个，发 `note: x omitted because of collinearity (...)` 并写入 `model_info['omitted']`（`[{variable, reason}]`，与 `sp.regress` 同形）。此前这些入口把秩亏设计直接交给优化器，返回 1e13 量级的系数、0 / 1e6 / NaN 的标准误，多数没有告警（书中 Childcare 例子把一个分类变量的全部虚拟变量和常数项一起放进倾向得分模型）。**新增基于似然的估计器时接上这一步**，不要依赖 `pinv` 或"Hessian 奇异"告警。判据是逐列的（单位化后对已保留列投影，剩余长度小于 1e-9 才剔除），不是对整个设计矩阵的秩容差，所以均值大、离散小的回归元（年份）不会被误删；`sp.regress` 仍用它自己的结构化检测（NIST 病态但满秩的设计）。二值模型的分离告警（`logit_probit._warn_if_separated`，`sp.glm` 的二项族共用）的判据是"线性指数把所有观测分对"或"拟合概率在机器精度上等于 0 / 1"，旧判据另要求 99% 的拟合概率贴边，小样本下会漏报。
- **`regression/gee.py`（`sp.gee`，1.39 起）**：Liang-Zeger 矩估计。三家参考实现在三处约定上各不相同，**都已精确定位，不要"修"成一致**：(1) 矩的除数——R `gee` 用 `N - p`（`dof_correction=True`，默认），Stata `xtgee` 用 `N`（`nmp` 才是 `N - p`）；(2) 稳健协方差——我们与 R `gee` 都是裸三明治，Stata `vce(robust)` 再乘 `G/(G-1)`；(3) 尺度——R 对所有分布族估计 φ，Stata 对 binomial / poisson 固定为 1（`scale=1`，只影响 model-based SE）。AR(1) 参数有两个矩估计，两个都提供：`corstr='ar1'` 是相邻配对的合并矩（= Stata `xtgee, corr(ar 1)`，两种除数下都对到 1e-7）；`corstr='ar-m'` 是 R `gee` 的 `"AR-M"`（各簇的平均相邻乘积之和 ÷ 各簇的均方之和，对到 1e-12）。平衡面板上两者只差自由度项，簇大小不等时才分开（示例数据上 0.557 对 0.568）。这一条第一轮曾记为未解释，是用平衡面板做黑盒试验（隐含除数恰为 `(m-1)(N-p)/m`）定位出来的，GPL 源码没有读。`sp.from_stata("xtgee ...")` 会把 Stata 的四个默认值（`corstr='exchangeable'`、`vce='model'`、`dof_correction=False`、binomial / poisson 的 `scale=1.0`）显式写进调用。
- **`regression/gam.py`（`sp.gam`，1.39 起）**：单变量 P-spline 光滑项（三次 B 样条 + 二阶差分惩罚 + 样本内和为零约束），与 `mgcv::gam` 的 `s(x, bs="ps")` 同基、同惩罚，固定平滑参数下逐位一致（1e-9），所以**改基函数、节点或约束之前先想清楚会不会丢掉这个可检验性**。三条约定：(1) `lambda_` 乘的是原始 `D'D`，mgcv 的 `sp` 乘的是 `D'D / S.scale`，换算 `lambda_ = sp / S.scale`；(2) 默认 `method='reml'`（mgcv 默认是 `GCV.Cp`，但其作者推荐 REML）——在线性真值的夹具上 GCV / UBRE 会把 edf 选到 8.6 / 9，REML 给直线；(3) GCV / UBRE 曲面可能有多个局部极小，我们用网格 + 精修取全局较低者，与 mgcv 选的不同时比**准则值**而不是曲线。所有求解都走「设计矩阵叠惩罚平方根」的 QR，**不要**退回正规方程（λ≈1e13 时会丢 5 位）。mgcv 是 GPL，只当黑盒用（`smoothCon` / `S.scale` / `gcv.ubre`），源码没有读。`s(x, by=d)`（d 为数值列）不做中心化、自带水平项，与 mgcv 的 `by=` 逐位一致；`vce=` / `cluster=` 的三明治以「曲线退化成直线时等于 `sp.poisson` 的 hc0 / robust / cluster SE」这个恒等式为证据，**不要**把 R 的 `vcov(gam, sandwich=TRUE)` 当参考——它另有一个没查明的小样本修正（约大 1%）。第五轮（2026-10-06）补上了 `te(x, z)`、`s(x, bs="tp")`、`s(g, bs="re")`，基与惩罚的构造在 `regression/_gam_terms.py`，引擎改为「惩罚列表」（每个惩罚一个 λ，一个项可以有多个，`fit.lambdas` 是全量）。黑盒对出来的 mgcv 约定，改之前先看：张量积的边际要先换成「k 个等距点上的函数值」参数化，每个边际惩罚除以自己的最大特征值，再 `lambda = sp / S.scale`；惩罚重叠时 REML 的对数行列式按总惩罚的非零特征值算，不能逐项相加；thin plate 核是 `|r|^3 / 12`，按特征值截到 k 维，超过 2,000 个不同取值时等距抽样；随机效应是单位阵岭惩罚、`S.scale = 1`，`lambda = scale / sigma_b^2`。`smooth_terms` 的检验是 Wood (2013)：`ref_df` 是 `2 diag(F) - diag(FF)` 之和，秩取非整数，p 值是两种特征向量符号选择的平均（mgcv 打印的统计量只是其中一种，所以**统计量本身只对到 12%，p 值对到 5e-6**，不要去「修」统计量），混合卡方尾部用 Imhof 反演；随机效应不给检验（方差在边界上）。`partial(simultaneous=True)` 是后验模拟的同时置信带。仍未做：多于两个变量的张量积、`ti()`、二元 thin plate、随机斜率。
- **教材驱动的小估计器**（2026-10 Hansen）：`sp.cnsreg`（约束最小二乘 / 有效最小距离）、`sp.nls`（参数写在花括号里，表达式由 `_stata_expr` 的封闭文法求值，不用 `eval`）、`sp.model_average`（Mallows / 刀切 / 平滑 AIC、BIC，单纯形上的 QP 在支撑集上解 KKT 得精确解）都在 `regression/`；`sp.pca` / `sp.factor` 在 `multivariate/`；`sp.jackknife` 在 `inference/_jackknife_general.py`，与 `sp.bootstrap` 对称。Stata 的 `factor, ml` / `ipf` 与 `nl` 默认容差较松，比对前先让 Stata 收紧容差；Stata 的 jackknife 把重复值存成单精度，标准误只能对到 1e-7。
- **设计护栏（`core/_design_guardrails.py`，2026-10-19 起）**：`sp.feols`（native 与 pyfixest 两条路径）/ `sp.fepois`（native）/ `sp.regress` / `sp.hdfe_ols` / `sp.panel`（fe / twoway / re / pooled）拟合后各调用一次 `check_design`，只写诊断、不改数。两项检查：(1) 单位与时期固定效应下分期开启的 0/1 处理，按 cohort × 时期的行数算 Goodman-Bacon 权重里「已处理单位作对照」的份额，与 `sp.bacon_decomposition` 的 `already_treated_control_weight_share` 是同一组权重（随机平衡面板上差 1e-12，测试守着），≥ 1% 报 `staggered_twfe`；(2) 处理在某列（或该列 × 时期）内恒定、该列比标准误的层级粗（HC1 / iid，或聚类嵌套在它里面），报 `treatment_cluster_level`。为了不误报：交互项的主效应、等于另两个 0/1 回归元乘积的列的因子不算处理；水平数不多于处理路径数的列（cohort 列、处理组指示）不算分配层级；与聚类交叉（单位 × 时期）的列不算；时期列不算。只检查用户层调用：调用栈上出现两层 frame-input shim（另一个 `sp.*` 函数在内部调用回归）就跳过，MCP / agent 层算用户。同一把闸门驱动会话级规格计数（`core/_spec_counter.py`）：族键是结果变量名 + 列名集合（不哈希数据），规格键含入口、公式、固定效应、方差、权重和使用的行数，所以同一调用重复（bootstrap、重跑）只计一次，换控制变量、换标准误、换子样本各计一次。**新增线性回归入口时接上这一个调用**，不要另写检查；违规项里的 `next_calls` 模板由 `agent/_enrichment.py::violation_next_calls` 变成 MCP 的 `next_calls`（`same_call: true` 表示用调用者的参数重跑本工具，去掉 `drop_arguments` 再加上模板参数）。1M 行面板上整套检查约 60–70 ms。
- **固定效应投影没收敛时（2026-10-19 起）**：交替投影在连通性差的固定效应图上（少数流动者串起的企业链、大量单元素组）会在迭代上限处停下，斜率可能差在第四位。`fast/_fe_direct.py` 把没收敛的列用稀疏直接解收尾：消去水平最多的一维（对角块），对其余水平的 Schur 补做分解（6000 阶以下稠密 LU，否则 SuperLU），奇异性用单位对角缩放后 1e-13 的对角平移处理，再迭代精化到加权组均值为零。两种方法互补：连通好的图投影几步就收敛、分解会大量填充；连通差的图投影爬行、分解几乎不填充。`sp.feols`（native，加权与否）和 `sp.hdfe_ols`（`Absorber.demean` 的三条路径）都接上了，结果记在 `model_info['fe_solver']` / `absorber.fe_solver`；直接解也失败才抛 `NumericalInstability`。fixest 0.14 在同样的数据上也停在不收敛处（800 企业链上 0.51981，真值 0.51983），所以这一项的参照是哑变量回归（R `lm`），不是 fixest。新的 HDFE 入口要检查收敛标志并接这个回退，不要丢掉 `_demean_core` / `_weighted_ap_demean` 返回的 `converged`。
- **`sp.feglm(family='negbin')` 与 `bias_correction=True`（2026-10-19 起）**：负二项（`fast/_fenegbin.py`、`fixest/_native_negbin.py`）的参照是 fixest 0.14 `fenegbin`（`fixef.tol=1e-11`，否则 fixest 自己的停止规则在 1e-7 左右）和 `MASS::glm.nb` 加哑变量；fixest 把 `theta` 列为系数 `.theta`，这里放在 `model_info['theta']`，系数表只放回归元，这样 predict / margins / test 不用特判。小样本因子同 fepois 的规则，只有一处 fixest 的约定是实测得来、没有文档：所有固定效应都嵌套在聚类里时，负二项的 `K` 比泊松多 1（把 `theta` 算进去），部分嵌套和 iid 时不算。fenegbin 不接受权重，带权的只对 `glm.nb(weights=)` 的点估计。偏差校正（`fixest/_feglm_bc.py`）照 Fernández-Val–Weidner（2016）公式写，对 alpaca 0.3.5 的输出核对：alpaca 默认 `dev.tol=1e-8` 会让未校正的斜率差 4e-5，生成参照时要 `dev.tol=1e-14`；校正后的方差在校正后的斜率处重估固定效应再算，不乘小样本因子（alpaca 的约定，与同一个 `sp.feglm` 不校正时用 fixest 因子不同，`vcov_type_detail` 写明）。alpaca 的二维聚类在这组数据上与一维相同，原因不明，所以校正时不提供二维聚类。fixest、MASS、alpaca 都是 GPL，只用输出和文档。
- **LDV 模型之后的 `sp.margins`（引擎 `postestimation/_ldv_margins.py`，适配器 `_ldv_models.py`，2026-10-19 起）**：mlogit / ologit / oprobit / gologit / tobit / intreg / heckman（ML）/ heckprobit / ivprobit（ML）各有一个适配器，把 Stata `predict()` 的统计量写成各方程指数与辅助参数的函数；引擎对连续变量沿「该变量移动各指数的方向」做五点差分（步长 2e-3 × 模型尺度，tobit 的尺度是 σ），对参数向量做五点差分得 Jacobian，用估计尺度（`(b, ln σ)`、`athrho` 等）上的完整 ML 协方差做 delta 法。新的 LDV 估计器只需在结果上挂 `_ml_state`（`theta`、`vcov`、各方程的项名）并在 `ldv_model` 里加一个适配器。约定：(1) 默认统计量跟 Stata 18：ivprobit 默认是 `xb` 不是概率；(2) ivprobit 的 `pr` 是 Stata 的 asf——以**观测到的**简化式残差为条件，margins 设反事实值时残差不动（`bind_base` 在 `at()` 之前取值），`pr fixedasf` 才是 Φ(xb)；(3) twostep 的 heckman 只给 `xb`，twostep 的 ivprobit 拒绝（系数按 Var(u|v)=1 标准化）；(4) Stata 的 margins 是数值导数，tobit `pr()`、ivprobit `pr`、heckprobit `p11` 的标准误只准到几个 1e-7，我们的数与闭式解的 complex-step 导数差 1e-8 以内，所以对 Stata 的容差是 2e-6，**不要**为了贴近 Stata 去改步长。证据 `tests/test_ldv_margins_stata.py`（夹具在 `tests/fixtures/ldv_margins/`，do 文件可重跑）。`sp.avg_slopes` 等 marginaleffects 风格的函数与 `contrast` / `pwcompare` 对这些模型拒绝并指向 `sp.margins(predict=)`。
- **`sp.heckprobit`（`regression/heckprobit.py`）与二元正态 CDF（`regression/_bivariate_normal.py`）**：参数化同 Stata `(b, g, athrho)`，对 Stata 18 系数 / 标准误 1e-9。二元正态 CDF 只有这一份（`sp.biprobit` 也用它），在 `arcsin(r)` 上做 32 点 Gauss-Legendre，消掉 |r|→1 时密度的奇点；旧的按 r 积分的 24 点规则在 |ρ| = 0.99 时差 9e-7。必须保持 complex-step 安全（不 clip、不转 dtype）。
- **`sp.intreg`（`regression/intreg.py`，2026-10-19 起）**：参数 `(b, ln σ)` 同 Stata `/lnsigma`；两端都缺的行不进 `e(sample)`（margins 的平均也排除它们，`_IntReg.sample_mask`）；下界大于上界**报错**（Stata 只是 note 后丢掉）。区间概率 `ln(Φ(b) − Φ(a))` 按 a 的符号选尾部算（`_log_prob_between`），complex-step 安全。只有一个截断点时与 `sp.tobit` 一致（测试守着）。
- **`sp.regress` / `sp.logit` / `sp.probit` 的 `design=`**：`design=`（复杂抽样设计，2026-10-19 起）只有一个方差入口：`survey/linearization.py::design_vcov`（= R `survey::svyrecvar`，含 strata / PSU / fpc / lonely-PSU / 校准），估计器只负责交出逐行贡献 `u_i`（`theta_hat - theta ≈ Σ u_i`，抽样权重已在里面；对均值归一的权重就是 `u/n`）。不要在估计器里再写一份 PSU 求和或 `G/(G-1)`。`design=None` 时代码路径与之前逐位相同；`design=` 与 `weights=` / `cluster=` / bootstrap 同用一律报 `MethodIncompatibility`。推断用 t(#PSU − #strata)（Stata `svy` 口径）。证据在 `tests/reference_parity/test_survey_causal_parity.py` / `test_survey_did_parity.py`（R survey 4.5，1e-14 量级）。 实现是先按抽样权重拟合，再用 `survey/_regression_design.py` 把协方差换成 `B M B`（与 `sp.svyglm` 一致）；与其他方差选项同用拒绝。
- **`sp.gologit`（`regression/gologit.py`，2026-10-19 起）**：gologit2（SSC，Williams）只当黑盒（输出与帮助文件，未读源码；对照时装在私有目录，不进用户的 PLUS）。参数化 `Pr(Y > c_j) = F(a_j + x'b_j)`，方程以类别值命名、受约束变量在每个方程里重复、协方差按映射矩阵展开（奇异），与 gologit2 的 `e(b)` / `e(V)` 同形。gologit2 停在 Stata ml 的默认容差，所以对它只能到 1e-6。没做 `autofit`、`gamma` 参数化和 cloglog / loglog / cauchit 链接。
- **`sp.fepois` 之后的 margins（`postestimation/_fe_delta.py`，2026-10-20 起）**：依赖被吸收效应的**平均量**（`sp.margins` 的 AME、`margins_at` 及其对比、`contrast` / `pwcompare`、`avg_slopes` / `avg_predictions` / `avg_comparisons` 与 `by=`）把效应当作参数做 delta 法，= Stata `poisson y x i.g` 或 `ppmlhdfe ..., d` 之后的 `margins`（Stata 参考在 `tests/fixtures/margins_fe/stata_margins_fe_delta.do`，两者彼此相差 1e-8）。实现不展开 `(k + L)` 阶协方差：效应的梯度来自「对各评估行线性指数的导数」`u`（`g_a = D_eval' u`），用 Ω = wμ 加权的 FWL 分块解 `h = Z A^-1 g`，模型 / 稳健 / 一维聚类三种方差都是 `h` 的二次型；小样本因子从拟合自己的系数协方差读出（必须是原始三明治的**标量倍**，否则拒绝），所以与 Stata 只差这个标量（fixest 的 `(n-1)/(n-K)`），测试按系数 SE 之比换算后对到 1e-8（一维）/ 1e-6（二维，拟合本身的二维 SE 对 Stata 只到 5e-7）。拟合必须是 native（`fe_state.sample_index`），并用传入的数据复现 μ 与得分方程，不符就拒绝。仍拒绝：逐行量、`method='mem'`、二维聚类、logit / probit（Stata 对 `i.g` 的 logit 是附带参数估计量，不是吸收拟合的参照）、OLS 的预测边际。marginaleffects 表的 `attrs['jacobian']` 在这条路径上是估计值协方差的因子、`vcov_coefficients` 是单位阵，`sp.hypotheses` 照用。
- **`sp.feols` / `fepois` / `feglm` 的聚类写法（`core/_vcov_spellings.py`，2026-10-21 起）**：所有明确表示一维（或多维）CRV1 / CRV3 聚类的写法都归一为 `{"CRV1": "a"}` / `{"CRV1": "a+b"}` / `{"CRV3": "a"}`：字典键 `CL1` / `CR1` / `cluster`（以及 `_vcov_spec._SE_KIND_SYNONYMS` 里映射到 cluster 的所有缩写）、`CL3` / `CR3`，大小写不限，值可以是列名、`"a+b"` 或列名列表；字符串 `"cluster:id"`、`"cluster(id)"`、`"cluster = id"`、`"CL1:id"`、`"~id"` 先改写成 house style 的 `"cluster id"`，再交给已有的 `stata_vce_to_fixest`；单独的 `"cluster"` 配 `cluster=` 等于只给 `cluster=`。归一化是一个装饰器，放在 `@markout_clusters` 之上，所以新写法下缺失聚类变量的行与 `cluster=` 一样被剔除。结果与 `cluster='id'` 逐位相同（`tests/test_feols_vcov_spellings.py` 用 `==` 断言）。不认识的写法报 `MethodIncompatibility` 并提示 `cluster=` / `vce='cluster id'`；pyfixest 自己的 `AssertionError` 在调用边界改抛同一异常。`{'CR2': ...}` 不翻译（CR2 走 `vcov='CR2', cluster=` 的另一条路径），报错时给出这个写法。`sp.hdfe_ols(vce=)` 同样接受这些聚类写法（经 `cluster_from_vce`），未知的 `vce=` 报 `MethodIncompatibility`。**没有改 `core/_vcov_spec.py`**：它在 56 个 parity trace 的估计路径上，新逻辑放在新文件里，只复用它的同义词表和解析函数。
