# 面板、多层模型、前沿、动态面板 GMM

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`multilevel/` / `frontier/` / GLMM**：v0.9.3–v0.9.4 有含正确性修复的大重构——用户引用旧数值时主动提示。
- **`gmm/_dynpanel/`**（`sp.xtabond` / `sp.xtdpdsys`）：求逆一律走 `_estimate.safe_inv`，不要直接 `np.linalg.inv`——`inv` 只在主元恰为 0 时报错，数值奇异的权重矩阵会原样返回量级 1e15 的噪声（Hansen 表 17.3 的两步权重秩 191/199，修复前标准误是 1e14 且无告警）。奇异时用的广义逆是 `sweep_ginv`（每步取剩余对角最大者为主元、共线矩条件置零），即 Mata 的 `invsym`；两步估计量在权重奇异时**依赖广义逆的取法**，Moore-Penrose 给出的是另一组数，换掉它就对不上 `xtdpd` / `xtabond2`。Windmeijer 校正里的一步协方差要去掉被置零的矩条件（`_fit.py` 的 `V1_step`）。`time_dummies=True` 的取舍规则跟 Stata `xtdpd`：没有变换方程行的期不建虚拟变量；有常数项时再从回归元里去掉最后一个、但保留在工具变量里。证据在 `test_hansen_methods_stata_parity.py`（abdata 上一步 / 两步 / 奇异权重三组，1e-9）。Stata 报的 instrument 数是秩，我们报列数。
- **`panel/` 的随机效应方差分量只有一份实现**：`panel/xt_tools._swamy_arora`，自由度按**秩**计（组内不变的回归元不占组内回归的参数），`panel/_cre.py::variance_components` 调它；每个回归元都随组内变化时仍用 linearmodels 自己的数。linearmodels 的 `RandomEffects` 按列数计，含行业虚拟变量这类回归元时 `sigma_e` / `theta` / 系数都会偏（2026-10 Hansen 第 17 章对照 Stata 查出）。**不要**再在别处重算这套分量。
- **`mackinnon1994_pvalue`（`panel/unit_root.py`）在拟合范围之上返回 1**（含常数 2.74、含趋势 0.70），与 Stata、statsmodels 一致；plm 在范围外继续代三次多项式，带趋势时 +3.25 给出 0.06，不要为了对 plm 去掉截断。
- **`sp.panel` 的三个 R² 按 Stata `xtreg` 定义（2026-10-18 起）**：`fe` / `re` / `be`（不加权）的 within / between / overall 是相关系数平方（`panel/xt_tools._xtreg_rsquared`，与 `xt_statistics` 共用这一份），和 Stata 18 `e(r2_w)` / `e(r2_b)` / `e(r2_o)` 对到 1e-14（`tests/test_panel_xtreg_rsquared.py`）。linearmodels 的 1 − SSR/SST 版本留在 `model_info['r2_linearmodels']`，`model_info['r2_convention']` 写明用了哪一种。加权、`twoway`、`pooled`、`fd`、CRE 仍是 linearmodels 的数：`xtreg` 没有对应量，换了也无从对齐。只有一个回归元时三种方法的 R² 完全相同，这是定义使然（相关系数与斜率大小无关），不是 bug。
- **`sp.xtivreg`（`panel/xtivreg.py`，2026-10-19 起）**：公式取自 Stata 手册 [XT] xtivreg 的 Methods and formulas，有三处按 Stata 的输出定（手册写法有歧义或与输出不符，测试在 `tests/test_xtivreg_stata.py`，非平衡面板八种变体 1e-12）：(1) `be` 以及 `re` 里求 `sigma_u` 的组间回归是**每组一行、不加权**（手册说每个均值出现 T_i 次，那样系数差 27%）；(2) `re` 的 `s2_nu = SSR_within / (N - n - K + 1)` 里 K 数的是**全部**回归元（含组内不变、组内回归用不上的那些），`fe` 里则是剔除后的个数；(3) EC2SLS 的工具变量是 X 的组内部分与组均值，**再加上 GLS 变换后的常数 `1 - theta_i`**（非平衡面板上它与组均值里的常数 1 不同；不加时差约 2e-3）。`vce='robust'` 即按 id 聚类，聚类因子 `G/(G-1)·(N-1)/(N-K)`。没有做 `fd`（需要时间变量）和 `small`（t / F 推断）。
- **`sp.xtpcse`（`panel/xtpcse.py`，2026-10-19 起）**：Stata 手册说共同 AR(1) 系数是各面板系数的平均、`np1` 时按 T_i 加权、默认按 T_i − 1；实际（非平衡、有缺口的面板上对出来的）权重是**每个面板的相邻观测对数**，`np1` 时再加一。缺口会切断 Prais-Winsten 的差分链（缺口后的第一个观测按 `sqrt(1 - rho^2)` 缩放）。`casewise`（默认）只用所有面板共有的时期估计面板间协方差，一个都没有时报错并建议 `pairwise=True`。23 种选项组合对 Stata 18 到 1e-12。
- **`sp.xttobit` / `sp.xtintreg`（`panel/xtintreg.py`，2026-10-19 起）**：自适应 Gauss-Hermite 以每个面板被积函数的**众数和曲率**定中心（Stata 的 mvaghermite 以后验均值和标准差定中心），两者都收敛到同一个积分：Stata 12 点与 40 点只差 3e-10，所以对 Stata 40 点比。complex-step 求分数时自适应参数取实部、固定不动（换元不改变积分）。xttobit 对 Stata 1e-7（含标准误与 LR）。xtintreg 的点估计与似然对 Stata 默认拟合到 1e-7，标准误差最多 0.5%（`sigma_e`）。**2026-10-20 查明在 Stata 一侧**：xtintreg 用解析 Hessian（`e(user)=xtintreg_d2`），在自适应积分（mvaghermite / aghermite）下它不是 Stata 自己似然的曲率——用 `from() iterate(0)` 对 Stata 的 `e(ll)` 做中心差分，得到 se(sigma_e)=0.0385837，等于我们的数，而它报告 0.0387655；换成非自适应 `intmethod(ghermite) intpoints(100)`，Stata 报告的标准误就等于这个曲率，与我们对到 1e-10（`intreg_gh100`，`tests/test_xttobit_stata.py`）。按 §5.1 第 3 步记为参考实现自身的问题（T4），对默认拟合的标准误仍用 1e-2，不要为了贴近它去改我们的 Hessian。只有 OIM 方差（Stata 两者也只有 oim / bootstrap / jackknife）。
- **`sp.xttobit` / `sp.xtintreg` 的输入与速度（2026-10-20）**：共线回归元按 `core/_collinear.py` 剔除（Stata 同样写 "x3 omitted because of collinearity"，夹具 `tobit_col_q40` / `intreg_col_q40`）；`ll >= ul` 拒绝（Stata 18 对 `ll(2) ul(1)` 跑到不收敛并照样出表）。区间行的 `ln(Phi(b) - Phi(a))` 在 `_log_prob_between_split` 里每个元素只算它保留的那一侧尾部，与 `regression/intreg._log_prob_between` 逐位相同（有测试）。曾试过用实数算术展开复步（快 3 倍），参数与似然不变但标准误变 1.5e-12 到 5.5e-12：中心差分 Hessian 本身对步长的敏感度是 2e-11 到 9e-11，对 theta 一个 ulp 的变动也有约 7e-12，所以这个量级的差别在标准误的数值分辨率之下；为保持逐位一致没有采用，需要更快时可以重新考虑。
- **`sp.xtregar`（`panel/xtregar.py`，2026-10-20 起）**：对 Stata 18 `xtregar` 29 组运行全部对到 1e-15（`tests/test_xtregar_stata.py`，夹具含间隔时间、平衡子集、每种 rhotype 的迭代与 twostep、`rhof`、`lbi`）。逐条约定，**不要改回**：(1) ρ 由**去均值数据、不带常数**的迭代 Prais-Winsten 估计（Stata 手册只说“在去均值数据上跑 prais”，带常数时差 1e-4），间隔后的一期按序列重新开始（乘 `sqrt(1-ρ²)`），收敛判据 `|Δρ| < 1e-6` 与 Stata `prais` 相同，要逐位一致就不能迭代到更紧；`onestep` 不迭代。(2) `theil = tscorr·(N−k)/mc`、`nagar` 用 `k`（都含常数），`mc` 是相邻对数——与 `sp.prais` 的 `k+1` 约定**不同**，两者各自对 Stata。(3) 给定 ρ 后用 Baltagi-Wu 变换（间隔 d 期用 `ρ^d`）。FE：丢每个面板第一期、变换数据上做 within（加回总均值）；`sigma_u` 是**原始**数据估计样本上 `ȳ_i − x̄_i b` 的面板级标准差；`r2_b` 是观测级（面板均值展开到观测）的相关；`F_f` 的混合模型用**变换后的常数列**。RE：`sigma_u = sqrt(σ̂_µ²/(1−ρ²))`（变换把面板效应缩放了 `sqrt(1−ρ²)`），θ 分位数按观测、Stata `_pctile` 定义；`r2_b` 是面板级相关。LBI：`d1` 从每个面板第二期起算（相邻对差平方 + 间隔后一期的平方），`d2` 是后面跟着间隔的那些期。**两处有意偏离**：FE 的 `_cons` 点估计是 within 截距除以 `1−ρ`（同 Stata），标准误也除（Stata 不除，模拟显示 Stata 的小约 `1−ρ` 倍，测试里有）；RE 的 Wald 统计量与 Stata 相同但自由度取斜率个数 p（Stata 标 `chi2(p+1)`）。FE 中无面板内变异的回归元按 Stata 省略并告警。暂不支持权重（Stata 仅 FE + regress/freg 或固定 ρ 时允许）与 `sp.from_stata` 翻译。
- **`sp.mmqreg`（`panel/mmqreg.py`，2026-10-20 起）**：MSS (2019) 的位置-尺度分位数回归，固定效应按 Rios-Avila 等 (IZA DP 17262) 的做法“剔除后加回均值”（保留常数项，常数项无解释意义），多组固定效应用 `hdfe.demean`（容差 1e-14）。逐条约定，**不要改回**：(1) `q(tau)` 取标准化残差的第 `floor(n tau)+1` 个次序统计量（`n tau` 为整数时取上端，即 Stata `qreg` 对常数模型返回的顶点）；(2) 密度是 `qreg` 默认的 Hall-Sheather “fitted” 差商，与 `mmqreg` 的 `e(fden)` 对到 4e-15；(3) `q` 的影响函数是 `mmqreg` 用的 `[σ_i(τ − 1{ε_i ≤ q})/f − ν_i − q(ν̃_i − σ_i)]/σ̄`，论文式 (13) 第一项少了 `σ_i/σ̄`，照论文写对不上（差 1–7%）；(4) `vce='gls'` 是论文 2.2.3 的分块乘积形式，`robust` / `cluster` 不乘小样本因子——三者与 Stata 18 `mmqreg` 2.6 的 12×12 协方差都对到约 1e-14（单向、双向、无固定效应）。**单观测组**：其位置残差和拟合尺度都是 1e-16 量级的舍入噪声，Stata `mmqreg` / `xtqreg` 保留它们，0/0 的“标准化残差”进入分位数排序，夹具上让 `q` 移了一个次序统计量（`singleton_kept`）；我们迭代删除并告警。**与 `xtqreg` 1.3 的差别（T4，作者自己的实现，黑盒）**：系数、`e(q)`、位置与尺度系数对到 1e-10；`e(V_location)` / `e(V_scale)` 是我们的 cluster 方差乘 `G/(G−1)(N−1)/(N−K)`（测试里复现）；分位数系数的协方差是另一种 GLS 形式——把它拆成 `a·M + b(m₂γ'+γm₂') + cγγ'`（`M = (Z'Z)⁻¹Σzz'σ²(Z'Z)⁻¹`、`m₂ = (Z'Z)⁻¹Σzσ²`）能精确拟合，`a` 对应的矩是未中心化的 `E[ε²]`、`E[εε̃]`、`E[ε̃²]`（`mmqreg` 用 `ε̃ − 1`），`b` 对应 `κ₃ = (1{·}项/f − ε − qε̃)/σ̄`（同一个 Hall-Sheather 密度，三个分位点到 1e-9），`c` 里乘的常数（夹具上 1.06609，而 `mean(σ²) = 1.09239`）没有找到来源。结果是 `xtqreg` 的标准误比 `vce='gls'` 大 0.6%–31%。没有 `vce` 能复现它，所以 `sp.from_stata` 暂不翻译 `xtqreg` / `mmqreg`。Stata 参考在 `tests/fixtures/mmqreg/stata_mmqreg.do`，两个 SSC 包装在 scratchpad 的私有 PLUS 目录，未读源码。
- **`gmm/_dynpanel` 的 Arellano-Bond AR 检验（2026-10-20 clean-room）**：旧的 `arellano_bond_ar_test` / `ar_test_cross_basis` 自称逐项照搬 xtabond2 的 `_ARTests`（GPL-3），删除未读后按 Roodman (2009) 第 3.5 节与 xtabond2 帮助页重写为 `serial_correlation_test`，规格 `docs/dev/cleanroom/dynpanel_ar.md`。**改这里时不得阅读 xtabond2 的 ado / mata 源码**。黑盒钉住的约定：检验在一阶差分残差上做（FOD 估计后重建差分设计）；稳健项按面板单位求和（`cluster()` 只经 Avar 进入）；经典项用 i.i.d. 水平误差隐含的协方差（FOD 用平衡网格的算子），水平方程行不进入，`h=1` 时用单位阵。同轮修正：FOD 与 `h=1` 下经典 σ̂² 不再除以 2（⚠️ correctness，SE 约放大 √2、Sargan 减半）。与 xtabond2 剩下的差别是 σ̂² 的除数（`N*-k` 对 `N*`），以及 system + FOD + `h(1)` 时 xtabond2 的经典 AR 尺度（未追查）。
- **`sp.panel` 的 `ssc` 默认 1.42 起是 `'stata'`（2026-10-24 用户授权决定，2026-10-29 生效）。** `ssc=None` 在 `_ssc.default_change_applies` 为真的配置上解析为 `'stata'`（一维聚类，`be` 除外；fe / twoway / re / CRE 的 `robust='robust'`，Stata 在这些方法下把它读成按面板变量聚类；RE 家族的 z），其余（经典 fe / twoway / pooled / fd / be、kernel、Driscoll-Kraay、二维聚类）两种口径数字相同或没有 Stata 对应，保持 linearmodels 的缩放。`model_info['ssc']` 写明实际口径；`ssc='linearmodels'` 显式保留旧数字，比较 `plm` / `feols(vce='hetero')` 的测试都要显式写它。FD 按时间聚类在默认路径上现在可以拟合（Stata `regress D.y D.x, cluster(t)`；linearmodels 拒绝）。未知聚类列在 Stata 路径上也报 `ColumnNotFound`（此前是裸 `KeyError`）。测试 `test_inference_conventions_stata_parity.py::test_panel_ssc_default_is_stata_exactly_where_it_moves_numbers` 逐格核对。35 号 Track A 模块显式传口径，翻转后复现无漂移；`tests/reliability/` 的三个研究脚本显式写 `ssc='linearmodels'`，因为存储结果是在旧默认下算的。
- **`sp.mixed` 的三层嵌套与 LR 检验（2026-10 选项扫描）**：三层模型的随机效应一律以 `(外层, 内层)` 对为键（`random_effects` 是两级索引，`predict(data)` 需要两列）；班级编号在各学校内重复（1, 2, ...）是常见编码，只按内层标签做键会把不同学校的班级合并。对线性模型的 LR 检验按 Stata `mixed`：ML 对 ML、REML 对 REML（OLS 的 REML 准则为 `-(n-p)/2·log(2π·RSS/(n-p)) - (n-p)/2 - log|X'X|/2`），一个方差参数用 chibar2(01)，多个用 chi2(k)；夹具与 Stata 18 对到 1e-6（`tests/test_multilevel_scan_oct2026.py`）。
- **`sp.gmm` 的 J 与推断（同轮）**：`method='onestep'` 不报告 Hansen J（非有效权重下不服从 chi2，Stata `estat overid` 同样不提供）；`vcov='hac'` 不给带宽时用 `floor(4(n/100)^(2/9))` 个滞后（带宽 = 滞后 + 1）；`small=True`（默认）用 t(n−k)，`small=False` 用 z，与 Stata `gmm` / R `gmm` 一致。
- **`sp.xtlsdvc` 的自助法（同轮）**：参数自助法按 `rho·y_{t-1} + x'b + eta_i + e` 只在估计所用的格子上重生成 y（间隔后的一期与各单位首期保留观测值作为初值），`eta_i` 是修正后系数下各单位残差的均值；模拟面板上 rho 的自助标准误 0.0268，对蒙特卡洛标准差 0.0272。
- **`sp.akm`（`panel/akm.py` + `_akm_kss.py` + `_akm_graph.py`，2026-10-28 起）**：AKM 工人 / 企业固定效应与方差分解（plug-in、Andrews 等 2008 同方差修正、KSS 2020 留一修正）。约定，**不要改回**：(1) 固定效应不用交替投影：消去工人效应后企业方程是企业图的拉普拉斯 `L = F'M_D F`，每个连通集接地一个企业后用 `splu` 精确求解（AKM 图连通性差，交替投影收敛慢）；企业效应在每个连通集内按人年加权均值为零，工人效应带水平。(2) 留一连通集 = 删掉所有"桥"观测后的最大 2-边连通分量（`P_ii = 1` 恰好等价于该观测是二部多重图的桥；只出现一次的工人是悬挂边；同一工人-企业对出现两次以上的边永远不是桥），按企业数取最大（与 pytwoway 的 `component_size_variable='firms'` 一致）。一次去桥即可，不需要迭代。(3) `P_ii` 与三个 `B_ii` 都只依赖工人到过的企业：`P_ii = 1/T_w + g'Gg`，`g = e_f - fbar_w`，`G` 是接地逆；`exact` 用稠密 `J×J`（`EXACT_MAX_FIRMS = 3000` 以内），`jla` 把每个二次型写成 `(Ya)'(Yb)` 再用 Rademacher 草图（3×n_draws 次稀疏求解，带种子），`1/(1-P_ii)` 的 Jensen 偏差未做修正（open item）。(4) `sigma_i^2 = (y_i - ybar) e_i / (1 - P_ii)`：结果以均值中心化，使估计量对 y 加常数不变（作者代码与 pytwoway 同此）。(5) 协变量与 `time` 指示变量先用完整模型 `sp.hdfe_ols('y ~ x + i.time | worker + firm')` 偏出，分解的是 `y - x'b`，杠杆值是双向模型的（作者代码的做法）；同方差修正的自由度扣掉协变量个数。证据：与 pytwoway 0.3.21 在同一夹具上留一集合逐行相同、plug-in / var(psi) / 残差方差到 1e-10；pytwoway 精确迹在 var(alpha) 上把 `(W'W)^{-1}` 当向量加（`Dwinv` 是一维数组被按行广播），同方差情形恰好少 `(n_w-1)/n`，测试按这个恒等式钉住，KSS 的 var(alpha)/cov 对 pytwoway 的 Hutchinson 迹做 4 个 MC 标准误的筛查（S 级）；已知真值蒙特卡洛（固定设计、300 次误差重抽）断言 plug-in 偏差等于 `sum B_ii sigma_i^2`、KSS 无偏、同方差修正的期望等于解析式；`B_ii` / `P_ii` 与稠密 `(X'X)^{-1}` 逐元素相等。函数名 `akm` 与 bartik 里 Adao-Kolesar-Morales 的 'akm' 方差无关，docstring 已注明。
- **`sp.hdfe_ols(...).fixef()`（`panel/_hdfe_fixef.py`，2026-10-28 起）**：拟合时（OLS、吸收项全为因子、无工具变量）在结果上记 `_hdfe_fe_state`（**不是** `_fe_state`：后者会让 margins / wild bootstrap 把 FEOLSResult 当成 fixest 结果处理）。效应由 `y - x'b - e` 用 `fast/_fe_direct._Solver` 精确解出，再按 reghdfe 6.13 的保存口径归一：第 k≥2 个吸收项在它与第 1 项构成的每个连通集内（加权）均值为零，第 1 项全样本均值为零，剩下的就是 `_cons = ybar - xbar'b`（`absorb_constant=False`，放在 `.attrs['constant']`）；默认 `absorb_constant=True` 把常数并进第 1 项，使效应之和加 `x'b` 等于拟合值。交互项一律以 `"a^b"` 为键（MultiIndex），与翻译器对 `a#b` 的写法一致。Stata 18 reghdfe（`tolerance(1e-14)`）的保存效应本身只准到 ~1e-7（其拟合值与精确解差 3e-8），测试容差 1e-6；aweight 的加权归一也对过。
