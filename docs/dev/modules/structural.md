# 结构模型（BLP、路径分析、生产函数）

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`structural/blp.py`（`sp.blp` 的随机系数部分，2026-10 按 BLP 1995 复现文章修订）**：数值内核在 `_blp_core.py`，结果类在 `_blp_result.py`，转移比例与加价在 `_blp_post.py`；Berry (1994) 的 logit / 嵌套 logit 与 `sp.blp_instruments` 是同日另一条线加的，没有外层循环，这里的改动不影响它们。外层是带解析梯度的 L-BFGS-B（`sigma >= 0`），梯度是 `2 (dδ/dσ)' Z W Z'ξ`（线性参数的一阶条件消掉了它们那一项）；压缩映射逐市场做 SQUAREM，收敛判据仍是「一步普通迭代的位移小于 tol」。**目标函数有多个局部极小**：BLP 汽车数据上从 0.5 出发停在高 7% 的那个，所以第一步默认从 4 个起点出发（`sigma0` 加 `c / sd(x_k)`，c = 0.05、0.25、1），不要改回单起点。σ 落在零边界时 `dδ/dσ` 按对称性为零，联合三明治会除以它（旧结果里 35 这样的标准误就是这么来的）：该参数标准误记 NaN、其余按固定它来算，`model_info['sigma_at_bound']` 列出。转移比例必须用份额导数 `(ds_k/dp_j) / (-ds_j/dp_j)`，不是弹性之比（旧实现少了 `s_k / s_j`，行和到过 3.4）。价格带正态随机系数时会有模拟消费者的价格系数为正，出现正的自价格弹性就告警并计数，不要静默。证据是与 pyblp 共用积分节点的对照（`test_blp_pyblp_parity.py`，估计 1e-12、转移比例 1e-7、加价 1e-6；pyblp 是 MIT，装在环境之外，夹具由 `_generate_blp_pyblp.py` 重生）。未做：消费者人口特征（原文的 `ln(收入 − 价格)`）、供给侧联合估计、对数正态系数。
- **`structural/path_analysis.py`（`sp.path_analysis`）**：解析器在 `path_analysis.py`，估计只有一个引擎 `_sem_engine.py`（观测变量路径模型、潜变量 `=~`、均值结构、增长曲线都是同一个 `v = alpha + B v + zeta`，载荷就是 `B` 的一项）——新增模型类型往引擎里加参数种类，不要另起一套似然。参考是 lavaan；潜变量模型的容差 5e-6 是 lavaan `nlminb` 的停止准则，不是方法差异。**`auto_cov_y=False` 是有意的默认**：`lavaan::sem` 会自动让终端结果变量的扰动相关，Stata `sem` 和这里都不会，对照 lavaan 时两个以上终端结果要传 `auto_cov_y=True`。`missing='fiml'` 按缺失模式分组求似然，标准误用观测信息（对梯度做数值差分），饱和模型矩用 EM；外生变量缺失的行仍然删除。未实现：多组、分类指标。
- **`structural/production/op_lp_acf.py`（OP / LP / ACF）**：第二步在「产出减均值」上进行，马尔可夫多项式的基建在标准化后的滞后生产率上（`_markov_residual`、`_uncentre`），**不要**改回原始幂：对数产出加一个常数只是换计量单位，旧写法下 LP 的资本系数会动 1e-5、并把已收敛的拟合报成未收敛（2026-10-12 用 R `prodest` 自带的智利面板查出）。`productivity_process['rho']` 是生产率对其滞后的线性投影斜率，不是多项式的一次项系数（后者是 g 在 0 处的斜率，真实数据上给出过 −5.79）。ACF 是恰好识别的矩条件的**精确根**；R `prodestACF` 在智利面板上停在准则 6e-5 的非根局部极小（约 0.15 / 0.15 / 0.13，随种子变），我们的根是 0.71 / 0.75 / 0.20，两者不是同一个数，不要去对。自助法的标准误不做稳健化，只另报 `boot_se_iqr` 与分位数区间并告警。**总产出口径（代理变量同时作为投入）有意不做**：在完全满足 LP 假设的模拟里，矩条件 `(k_t, m_{t-1})` 定不住资本与原材料系数（真值 0.2 / 0.5，估计值在 −42 到 34 之间）。
- **`structural/blp.py`（`sp.blp` / `sp.blp_instruments`，2026-10-12 起含 Berry 1994）**：`x_random=[]` 是 Logit，再加 `nest=` 是嵌套 Logit，两者都是反解份额后的线性 IV-GMM，不经过收缩映射的优化；`gmm_steps=1` 的权重矩阵是 `(Z'Z)^{-1}`，估计量恰为 2SLS、标准误是 HC0（与 `sp.iv(robust='hc0')` 的恒等式是测试之一），默认仍是两步 GMM。`rho` 在线性步里估计，但放在 `nonlinear_params`（pyblp 的位置）。默认工具变量出自 `blp_instruments`（同厂商其他产品、竞争对手、同组产品的特征之和与个数，等于 `pyblp.build_blp_instruments`），**不要**再把 `x_linear` 本身放进排除工具变量：它已在工具变量矩阵里，重复一遍 `Z'Z` 就奇异（此前默认路径因此根本跑不了）。冗余工具变量由 `independent_columns` 剔除，自建的不告警、用户给的告警。参考是 pyblp（MIT，不装进 venv，装到临时目录后跑 `_generate_berry_logit_pyblp.py`），对照时要 `center_moments=False, W_type="robust", se_type="robust"`，它的目标函数是我们的除以 N。带随机系数的嵌套 Logit 直接拒绝，没有实现。BLP (1995) 表 III 的 IV 列（−0.216）用公开数据复现不出来（2SLS −0.136，LIML −0.244，pyblp 同样是 −0.136），那不是我们的 bug，不要为对上它去调设定。汽车数据集没有内置，再分发条款未核实。
