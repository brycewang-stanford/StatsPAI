# 结构模型（BLP、路径分析、生产函数）

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`structural/blp.py`（`sp.blp` 的随机系数部分，2026-10 按 BLP 1995 复现文章修订）**：数值内核在 `_blp_core.py`，结果类在 `_blp_result.py`，转移比例与加价在 `_blp_post.py`；Berry (1994) 的 logit / 嵌套 logit 与 `sp.blp_instruments` 是同日另一条线加的，没有外层循环，这里的改动不影响它们。外层是带解析梯度的 L-BFGS-B（`sigma >= 0`），梯度是 `2 (dδ/dσ)' Z W Z'ξ`（线性参数的一阶条件消掉了它们那一项）；压缩映射逐市场做 SQUAREM，收敛判据仍是「一步普通迭代的位移小于 tol」。**目标函数有多个局部极小**：BLP 汽车数据上从 0.5 出发停在高 7% 的那个，所以第一步默认从 4 个起点出发（`sigma0` 加 `c / sd(x_k)`，c = 0.05、0.25、1），不要改回单起点。σ 落在零边界时 `dδ/dσ` 按对称性为零，联合三明治会除以它（旧结果里 35 这样的标准误就是这么来的）：该参数标准误记 NaN、其余按固定它来算，`model_info['sigma_at_bound']` 列出。转移比例必须用份额导数 `(ds_k/dp_j) / (-ds_j/dp_j)`，不是弹性之比（旧实现少了 `s_k / s_j`，行和到过 3.4）。价格带正态随机系数时会有模拟消费者的价格系数为正，出现正的自价格弹性就告警并计数，不要静默。证据是与 pyblp 共用积分节点的对照（`test_blp_pyblp_parity.py`，估计 1e-12、转移比例 1e-7、加价 1e-6；pyblp 是 MIT，装在环境之外，夹具由 `_generate_blp_pyblp.py` 重生）。未做：消费者人口特征（原文的 `ln(收入 − 价格)`）、供给侧联合估计、对数正态系数。
- **`structural/path_analysis.py`（`sp.path_analysis`）**：解析器在 `path_analysis.py`，估计只有一个引擎 `_sem_engine.py`（观测变量路径模型、潜变量 `=~`、均值结构、增长曲线都是同一个 `v = alpha + B v + zeta`，载荷就是 `B` 的一项）——新增模型类型往引擎里加参数种类，不要另起一套似然。参考是 lavaan；潜变量模型的容差 5e-6 是 lavaan `nlminb` 的停止准则，不是方法差异。**`auto_cov_y=False` 是有意的默认**：`lavaan::sem` 会自动让终端结果变量的扰动相关，Stata `sem` 和这里都不会，对照 lavaan 时两个以上终端结果要传 `auto_cov_y=True`。`missing='fiml'` 按缺失模式分组求似然，标准误用观测信息（对梯度做数值差分），饱和模型矩用 EM；外生变量缺失的行仍然删除。未实现：多组、分类指标。
- **`structural/production/op_lp_acf.py`（OP / LP / ACF）**：第二步在「产出减均值」上进行，马尔可夫多项式的基建在标准化后的滞后生产率上（`_markov_residual`、`_uncentre`），**不要**改回原始幂：对数产出加一个常数只是换计量单位，旧写法下 LP 的资本系数会动 1e-5、并把已收敛的拟合报成未收敛（2026-10-12 用 R `prodest` 自带的智利面板查出）。`productivity_process['rho']` 是生产率对其滞后的线性投影斜率，不是多项式的一次项系数（后者是 g 在 0 处的斜率，真实数据上给出过 −5.79）。ACF 是恰好识别的矩条件的**精确根**；R `prodestACF` 在智利面板上停在准则 6e-5 的非根局部极小（约 0.15 / 0.15 / 0.13，随种子变），我们的根是 0.71 / 0.75 / 0.20，两者不是同一个数，不要去对。自助法的标准误不做稳健化，只另报 `boot_se_iqr` 与分位数区间并告警。**总产出口径（代理变量同时作为投入）有意不做**：在完全满足 LP 假设的模拟里，矩条件 `(k_t, m_{t-1})` 定不住资本与原材料系数（真值 0.2 / 0.5，估计值在 −42 到 34 之间）。
- **`structural/blp.py`（`sp.blp` / `sp.blp_instruments`，2026-10-12 起含 Berry 1994）**：`x_random=[]` 是 Logit，再加 `nest=` 是嵌套 Logit，两者都是反解份额后的线性 IV-GMM，不经过收缩映射的优化；`gmm_steps=1` 的权重矩阵是 `(Z'Z)^{-1}`，估计量恰为 2SLS、标准误是 HC0（与 `sp.iv(robust='hc0')` 的恒等式是测试之一），默认仍是两步 GMM。`rho` 在线性步里估计，但放在 `nonlinear_params`（pyblp 的位置）。默认工具变量出自 `blp_instruments`（同厂商其他产品、竞争对手、同组产品的特征之和与个数，等于 `pyblp.build_blp_instruments`），**不要**再把 `x_linear` 本身放进排除工具变量：它已在工具变量矩阵里，重复一遍 `Z'Z` 就奇异（此前默认路径因此根本跑不了）。冗余工具变量由 `independent_columns` 剔除，自建的不告警、用户给的告警。参考是 pyblp（MIT，不装进 venv，装到临时目录后跑 `_generate_berry_logit_pyblp.py`），对照时要 `center_moments=False, W_type="robust", se_type="robust"`，它的目标函数是我们的除以 N。带随机系数的嵌套 Logit 直接拒绝，没有实现。BLP (1995) 表 III 的 IV 列（−0.216）用公开数据复现不出来（2SLS −0.136，LIML −0.244，pyblp 同样是 −0.136），那不是我们的 bug，不要为对上它去调设定。汽车数据集没有内置，再分发条款未核实。
- **生产函数与 `sp.blp` 的选项扫描（2026-10-27，第六轮）**：OP / LP 第二步的起点、ACF 的起点和「离哪个根最近」都用**第一阶段多项式在样本均值处的斜率**（`op_lp_acf._slopes_at_mean`），不要改回原始多项式的一次项系数：那是各对数投入都为零处的斜率，对数资本换个单位（数据加一个常数）就会把 LP 带到另一个局部极小（模拟面板上资本 0.43 → −2.12，`stage2_converged=True`），把 ACF 带到另一个根。`sp.wooldridge_prod` 默认路径的 `h` 建在标准化的状态与代理变量上，投入在 GMM 内减去均值（均值并入两个截距再换算回来）；原始幂在对数投入 6–7 附近使 `Z'Z` 数值奇异。`productivity_process['rho']` 对它也是 TFP 对滞后的线性投影斜率，`markov_coef` 是滞后 TFP 的多项式（与 OP / LP / ACF 一致）。`convention='prodest'` 保持原始幂（与 Stata 的对齐）。`result.sample` 保留数据的行标签。`sp.blp(alpha=)` 决定 `summary()` 的区间水平；逐行输出（`markups()` / `mean_utility` / `own_elasticities`）带数据的索引；模型用到的列有缺失值直接拒绝。
- **`structural/ddc/`（`sp.ddc` / `sp.dgp_ddc`，2026-10-28 起，ECTA 94(5) 一轮）**：单主体、无限期、平稳、离散状态、i.i.d. 第一类极值冲击、效用对参数线性。数值内核在 `_core.py`（贝尔曼不动点、隐函数定理求导、Hotz-Miller 估值），输入与转移在 `_data.py`，结果类在 `_result.py`。三种估计量共用一套记号与同一个似然：`nfxp` 的内层先做逐次逼近、再做 Newton-Kantorovich 步，**不要**改成纯压缩映射（β = 0.9999 时要几十万步）；外层是带解析梯度的 BFGS，再用对解析梯度数值差分得到的 Hessian 做 Newton 打磨，收敛判据是参数步长。`ccp` 是 Hotz-Miller 的伪似然形式（即 Aguirregabiria-Mira 的一步估计量），选择值对参数线性，伪似然是带偏移项的条件 logit，用阻尼 Newton。`npl` 迭代到收敛时等于偏似然 MLE（测试 rtol 1e-7，受贝尔曼容差限制）。**三种方法的标准误都取偏似然在估计值处的信息**（AM 2002：单主体模型里各步伪似然估计量与偏似然 MLE 渐近等价），都不计第一步转移估计的抽样误差。价值函数里省略了 Euler 常数（对选择概率无影响）。`dgp_ddc` 的 `.attrs` 存的是嵌套 list 而不是数组：pandas 合并 DataFrame 时会比较 `attrs`，数组会让 `astype` / `concat` 抛 "truth value of an array is ambiguous"。未做：贴现因子估计、Rust 第三步全似然、未观测异质性（有限混合 / EM）、有限期、动态博弈。Rust 公交车数据的对照见下一条。
- **`sp.ddc` 对 Rust 公交车数据（2026-10-28 后续一轮）。** `sp.datasets.rust_bus()` 按 Rust 的 `stordat.gpr` 逐行离散化（读数 ≥ 换发动机里程即算换过；分箱用 ceil；去掉每辆车的第一个月；换发动机之后那一步按 1 起算的箱号计，比从状态 0 起算多一箱，第 4 组有 33 个增量受此影响）。用 `rust_sample` 行、`increment` 列的频率作 `transition=`（1-D 增量分布，2026-10-28 新增）、`vce='opg'`（即 Rust 的 BHHH），可复现表 V、VI、VIII–X：参数 2e-4 以内，标准误 5e-3 相对（原文是第三步全似然，我们是第二步）。默认的 `transition='increments'` 从状态 0 起算，结果与 Ferrall (2023) 的修正版一致（2e-4），与原文差 0.01–0.02，**这是约定差异，不要改回来**。原文有三处印刷值与数据不符，测试里逐条钉住：表 X 第 4 组 RC 印成 10.896，应为 10.0896（对数似然 −4495.135 吻合）；表 IX 第 1–3 组 β=0 的对数似然 −2710.746 低于表 VI 加表 VIII 之和，数据给 −2710.7245，近视检验统计量 4.716 而非 4.760（5% 结论不变）；表 VI 第 1–4 组 θ₃₁ 的 .348 是 .34882 的截断。Ferrall 网页上表 IX 第 4 组 β=0 的 RC 7.6538 是 7.6358 的数字颠倒。对 ruspy（commit 9a336e8）第 4 组：增量计数逐一相同、参数 1e-6。两步 CCP 在高里程稀疏格子上偏离 MLE（第 4 组 RC 9.13 对 10.07，仍在 2 个标准误内），NPL 20 步内收敛到 NFXP（1e-6）。未做：Rust 第三步全似然、贴现因子估计。
- **`sp.ddc(stage='full')` 与 β 的剖面似然（2026-10-28 剩余项一轮）。** `stage='full'` 是 Rust 第三步：选择与状态增量的全似然对效用参数和增量概率联合求最大值（`_full.py`）。自由参数是除最大观测增量外的各增量概率，未观测到的增量固定为 0；对增量的得分同样用隐函数定理（`dV/dq = (I − βF^P)^{-1} β Σ_a P_a (dF_a/dq) V`）。起点是两步估计，Newton 法求最大值，预测增益到舍入量级即视为收敛。β = 0.999999 时两步 NFXP 的 Newton 抛光会在舍入噪声上停下、报未收敛，这是原有行为，没有改；`stage='full'` 下的收敛标志取全似然那一步。β = 0 时选择概率与转移无关，两步与全似然逐位相同（Hessian 版块对角；BHHH 因样本交叉项不为零，差约 7e-5）。`increment=` 列按 Rust 口径（进入该行的那一步）给出增量；不给时用面板的下一期增量，两者全似然估计相同（1e-9）。对 Rust 表 IX/X（β = .9999，`vce='opg'`）：全部标准误与对数似然在印刷末位半个单位之内，参数 6 格中 5 格同样如此。例外两处：表 IX 第 1–3 组 θ₁₁ 4.82575 对 4.8259（两步值 4.82587 夹在中间，是 Rust 优化器的停点）；表 X 合并样本 θ₃₂ .36216 对 .3621（频率 .36219 也舍入为 .3622）。另有两处印刷错误：合并 90 箱 θ₃₀ 的标准误 .0052 是 .00528 的截断；表 X 合并样本 β = 0 的 θ₃₃ 标准误 .0143 是把估计值重复了一遍，应为 .0013。β = 0 的格子第三步改不了，第 1–3 组 RC 标准误 0.43% 的差距仍在。β 为列表时做剖面，`'estimate'` 在 τ = −log(1−β) ∈ [0, log 1e6] 上先 13 点网格再 Brent，区间用似然比反解，其他参数的标准误把 β 当作已知（约 45 次 NFXP，6–22 秒）。公交车数据上剖面单调升到上界（Rust："driven to 1"）；.98 与 .9999 之间似然比 < 3.84，.999999 时似然变动 < 0.01，但 .98 时 θ₁₁ 移动 1–2 个标准误，所以原文的 "negligible" 对似然成立、对 θ₁₁ 不成立；第 4 组似然比区间含 0，与表 IX 近视检验 p = .0529 一致。识别 β 需要足够频繁的更换：RC = 10、θ₁ = 2.5、β = 0.9 时几乎不更换，状态堆在最高一箱，β 无从识别，测试改用 RC = 6、θ₁ = 20。未做：非增量转移（`transition='estimate'` 或给定矩阵）的全似然；β 的 Wald 标准误（信息矩阵近奇异，按 Rust 的做法不报）。
- **`gmm/smm.py`（`sp.smm`，2026-10-28 起，AER 116(10) 一轮）**：不做成 `sp.gmm(method='smm')`：`sp.gmm` 的输入是逐观测矩函数、`method` 已经表示权重更新方式，而 SMM 的数据矩不依赖 θ、方差多一块模拟噪声。两者共用 `general_gmm._omega`（iid / HAC / cluster，SMM 一律中心化）与 `_safe_inv`，不要复制；`general_gmm.py` 本身没动。公共随机数：每个复制一个子 `SeedSequence`，每次求值都由它新建 `Generator`，在 `theta0` 处调两次模拟器核对输出一致（抓全局 RNG）。模拟修正 `c = 1 + N/(S N_s)`，`N_s` 取模拟器返回的行数，否则 `sim_n_obs`，否则假定等于 `N` 并记入 `model_info`；它要求模拟抽样独立于数据、跨 θ 复用、模型设定正确。数据矩协方差来源的优先级：逐行数据 > `data_moment_cov` > 在第一步估计处模拟（只有这条路需要两步）。雅可比是相对步长 `jac_step * max(1, |θ_j|)` 的中心差分（边界处单侧）；频率型模拟器对 θ 是阶梯函数，导数为零，直接抛 `NumericalInstability`，不要放宽。优化器之后有投影 Gauss-Newton 收尾，收敛判据是 Gauss-Newton 减量（`<= 1e-14 f` 或目标函数的舍入下限），不要改回步长判据（参数单位一变就失效，J 检验 Monte Carlo 里曾因此把真收敛的复制报成不收敛）。证据与未决项见 `docs/dev/aer-oct-2026/smm_matching.md`。
- **`structural/choo_siow.py`（`sp.choo_siow`，2026-10-28 起）**：内核在 `_choo_siow_core.py`（IPFP、非参数剩余及其 delta 方差、加权 Poisson GLM），结果类在 `_choo_siow_result.py`。`phi` 是联合剩余 Φ，Choo-Siow 原文的 total gains 是 Φ/2。非参数方差在多项抽样下是 `4/μ_xy + 1/μ_x0 + 1/μ_0y`（对数计数对比的系数和为零，`-11'/H` 项消掉）。参数版是 Galichon-Salanié (2024) 的加权 Poisson GLM（夫妻格权重 2、单身格权重 1），对凸对偶做牛顿法，停止判据是牛顿减量；夹心方差的 meat 用 Poisson（`diag(c)`），多项抽样多出的 `-cc'/H` 只沿 `(u, v) -> (u-1, v-1)` 方向，不影响 β 块，与 cupid 的多项方差对到 1e-11。参考实现是 cupid_matching 1.3（MIT，钉 numpy<2，装在临时环境里跑 `_generate_choo_siow_cupid.py`）：原版用 scikit-learn L-BFGS，β 的一阶条件只到 5e-6，所以夹具里另有一行把它的求解器换成 Newton-Cholesky（其余代码不变）作严格对照，不要拿 L-BFGS 那行去收紧容差。夫妻格为零时非参数 Φ 为 -inf 并告警，参数版照常用；某类型没有单身直接拒绝。反事实用 IPFP，均衡关于边际一次齐次。未做：异方差 / 嵌套 logit / 无单身变体、调查权重、反事实的标准误、最小距离估计量。
