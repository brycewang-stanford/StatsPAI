# 图形编辑器

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`plots/` 的图形编辑器（`sp.interactive` / `FigureEditor`，2026-10-16 重建）**：每种编辑是 `_editor_ops*.py` 里注册的一个操作（`Op`：类型化参数 + `apply` + `code`），实时编辑、生成代码、JSON 回放、schema 同出一处。三条不变式由 `tests/test_figure_editor.py` 逐像素检查：生成代码在新画的同一张图上复现编辑结果；`undo` / `reset` 回到原图（每步存 `_editor_state.capture` 快照，不是"从原图重放"）；保存的编辑列表回放结果一致。`test_every_operation_has_a_case` 要求**新增操作必须加一条 CASES**。约定：(1) `apply` 返回*解析后的完整状态*（网格改一项也记下颜色、透明度、线型、线宽），这样同一 slot 的旧编辑能从代码里删掉而结果不变；不满足这一点的操作不要给 slot。(2) 生成代码**只从 op + params 生成**，JSON 里传进来的 `code` 字段永远不执行、不拷贝。(3) 编辑器**不改全局 rcParams**：主题在 `rc_context` 里算出取值再写到这张图的元素上，字体用 `set_fontfamily` + `tick_params(labelfontfamily=)`；`Axes.set_title` 会把字号重置成 rc 默认，所以改标题文字用 `ax.title.set_text`。(4) 数据保护：角色先按 matplotlib container 认（errorbar 的点是 DATA、端帽和误差线是 CI），参考线只能靠几何判定，标签只能把元素往更严的方向归类；坐标范围保护用 `get_datalim` 等真实数据范围（`get_offsets` 对误差线和置信带返回 (0, 0)，旧实现因此会静默裁掉区间）；锁定元素不能变成看不见，被拒的编辑要原样恢复图。(5) 无界面后端（Agg、服务器、agent）上 `sp.interactive` 不得改图；GUI 后端的控件放在独立窗口。(6) `tests/test_figure_editor_all_plots.py`（slow，nightly 跑）把 registry 里每个 `sp.*plot*` 函数的 docstring 示例画出来，逐图检查代码复现与 reset；新绘图函数自动纳入，所以**示例要能画出 matplotlib 图**。第一次跑查出单元测试漏掉的三处：分类坐标轴、直方图透明边框被改色变成可见黑框、`sp.synthdid_plot` 用透明度编码时间权重的阴影（同色阴影透明度不一致即按数据锁定）。
- **`binscatter(method='binsreg')`（`plots/_binsreg.py`，2026-10-19 起）**：参照 R `binsreg` 2.2（GPL-3，**只当黑箱**：只比对它在测试数据上的输出，不读源码）。分箱点是 type-2 分位数（`np.quantile(..., method='averaged_inverted_cdf')`），区间右闭、第一箱左闭；点是"箱指示变量 + 协变量"同一回归里该箱的系数在协变量均值处的值，横坐标是箱内 x 的均值。箱数选择：ROT 用含协变量的全局二次多项式估计条件均值与条件方差、正态参考密度在 1.96 个标准差处截下界，再取 `max(ROT, ceil((2n)^(1/3)))`；DPI 用 HC1 夹心方差的箱块迹与"连续分段线性拟合的斜率 × x 对箱指示变量正交化"的偏差常数。这几处细节文献（CCFF 2024 补充材料 SA-4、binsreg 的 Stata Journal 文章）没写全，是对 40 个设计逐一比对 `binsregselect` 的整数输出定下来的，**改动前先跑 `tests/test_binsreg_parity.py`**。置信带的临界值是模拟的，只做 S 级筛查。`absorb` / `weights` / `cluster` / 质点（`masspoints`）调整未实现：前两者在 `method='binsreg'` 下拒绝；x 有重复值时箱数选择没有 binsreg 的质点修正（未决）。
- **`binscatter(method='classic')`（2026-10-27 第六轮选项扫描）**：参照 Stata 18 的 `binscatter`（Stepner，SSC，只比对 `savedata()` 输出）。残差加回的是 `y`、`x` 本身的（加权）均值；`absorb` 用 `fast/_fe_direct.residualise_codes` 精确吸收（加权），并且控制变量一起吸收，等于 `areg` 的一次回归；`weights` 下分箱用 Stata `_pctile` 的加权分位数（`output/sumstats.weighted_percentile`），区间右闭，箱内区间用 analytic weight 均值的标准误。三种设定与 Stata 对到 8 位有效数字（`tests/test_plots_output_option_scan_r6.py`）。未加权的分箱仍是 `np.percentile` 线性插值、区间左闭，与 Stata `xtile` 在分位点恰好落在数据点上时可能差一个观测（未决）。
