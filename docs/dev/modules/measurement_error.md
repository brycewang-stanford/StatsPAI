# 测量误差（回归元与协变量）

> 2026-10-28 随 Econometrica 94(5) 一轮新建。改动 `measurement_error/` 之前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`measurement_error/eivreg.py`（`sp.eivreg`，2026-10-28 起）**：与 Stata 18 `eivreg` 对到舍入（系数、标准误、F、R²、root MSE 差 5e-15，`tests/reference_parity/test_eivreg_stata_parity.py`，五个设计含 `[aw=]` / `[fw=]` / 零权重行）。公式见 [R] eivreg 的 Methods and formulas，三处容易写错、由 parity 测试钉住：(1) `S_jj = (1 - r_j)(N - 1) s_j^2`，`s_j^2` 是加权样本方差，`N` 是加权个数（aweight 先缩放到和为行数）；(2) 方差是 `A^{-1} H'WH A^{-1}`，**没有**小样本因子，aweight 下 `W` 取平方；(3) R² 是 `1 - (y'Wy - b'Ab)/TSS`，F 是斜率的 Wald 统计量除以斜率个数。权重为零的行退出样本（与 Stata `e(N)` 一致）。"信度太小"的判据是中心化 `[X, y]` 的修正二阶矩矩阵正定；单个误差变量时即 `r > R²(x 对其余回归元与 y)`，夹具上 Stata 的门槛在 0.4359 与 0.4360 之间，我们相同（解析下限 0.435934），越过时抛 `IdentificationFailure`（Stata 是 r(399)）。不带截距的模型和共线公式直接拒绝，不静默丢项。 2026-10-28 起另有 Track A 模块 `90_eivreg`：Stata 18 `eivreg` 与 R `eivtools::eivreg` 0.1-8（CRAN 已归档，装在私有库 `~/.statspai-rlib-eiv`，由 `STATSPAI_EIV_LIB` 指定）两侧都对到 6.7e-15。
- **`measurement_error/simex.py`（`sp.simex`，2026-10-28 起）**：已知误差标准差的加性正态误差，线性 / logit / probit / Poisson。抽样顺序是"每个 lambda（升序）× 每个复制 B，抽一个 `(n, 误差变量个数)` 的标准正态矩阵"，改顺序会改变固定种子下的所有数。每个 lambda 的 jackknife 方差是 `mean_b V_b - cov_b(theta_b)`（`ddof=1`），与 R `simex` 相同；朴素协方差对 GLM 取期望信息的逆（R `vcov.glm`），对最小二乘取经典式，`vce='robust'` 换成 HC0。R `simex` 的 `fitting.method="nonlinear"` 在系数路径近乎平坦时会在 `stats::nls` 里报错（屏幕夹具上就报了）；我们对该系数退回二次外推、告警并写入 `diagnostics['quadratic_fallback_terms']`，所以对 R 的筛查只覆盖二次和线性外推。`B` 沿用 R `simex` 与文献的名字（它是模拟次数，不是 bootstrap，所以不叫 `n_boot`）。GLM 拟合是 `simex.py` 里的私有 Fisher scoring（`mediation/_four_way_engine.fit_glm` 没有 probit 也不收权重）；以后有共用的 GLM 基元时迁过去。误差变量必须以原始列进入公式，同时出现在交互或变换里会被拒绝（扰动传不进那些项）。证据：已知真值（n = 20,000 时有理外推把线性斜率从 1.6 拉回 2，误差 0.04 以内）+ 恒等式（lambda = 0 等于 `sp.regress` / `sp.logit` / `sp.poisson`；误差为 0 恰为朴素估计量）+ 对 R `simex` 1.8 的 **S 级**筛查（8 个种子、间隔 `1000 + 100000k`，容差 5 个模拟差 SD，`tests/reference_parity/test_simex_r_screen.py`），不写成 parity。Stata 的 `simex` 不在 SSC 上，`net search` 找不到，没有 Stata 参考。
- **`measurement_error/noisy_covariates.py`（`sp.noisy_covariates`，2026-10-28 起，Agarwal-Singh 2026）**：按 arXiv v6 的算法（Econometrica 版是缩写）。训练折里缺失格填 0、观测格除以观测比例 `rho_j = max(观测均值, 1/m)`，对填充后的训练块做截断 SVD（复用 `matrix_completion._core._svt`，`theta=0`）；OLS 与平衡权重来自同一个伪逆 `P = pinv(B)`（`beta = P y`，`eta = P P' M`）；测试行只填充、**不投影**（论文的"隐式清洗"），不要"修"成也清洗测试行，那会破坏推断依赖的条件独立。常数项在清洗**之后**加（`add_constant=True`）：放进 SVD 里它的奇异值是 sqrt(m)，p 大时低于噪声底而被截掉；不加常数时 ATE 字典表示不了常数效应，论文自己的设计会给出 -0.27（真值 2.2）。`_pinv` 截断 `1e-9 * s_max` 以下的奇异值，numpy 默认容差会把精确低秩矩阵留下的 1e-15 级舍入奇异值也求逆。方差是 `mean(psi_centred^2)/n`（ddof 0，论文 Lemma D）；LATE 用 delta 方法得分 `(psi_Y - theta psi_D)/第一阶段`。`rank=None` 用 Gavish-Donoho 硬阈值（不在论文里，论文把秩当调参），有缺失时会多选（测试设计里真秩 3 选到约 12），论文说多选代价小、少选才有偏。折按处理组分层（LATE 按工具变量）。
  - **区间不覆盖的 1/p 阶偏差是真实的**：每个单位自身的噪声在保留的 k 个方向里仍在。Corollary 5.4 要求 `n^(2/3) <= p <= n^(3/2)`，`model_info["p_in_theory_range"]` 报告是否满足，但不告警，因为论文自己的 ADH 应用（n 约 1,444，p = 30）就在范围外。p = 30、n = 1,500、强混杂时部分线性估计 1.00，真值 0.70。
  - 论文自己的模拟设计（n = p = 100，秩 5，20% 噪声，k = 5）300 次重复：均值 2.24、平均 SE 0.38、覆盖 92%；论文报 2.22、0.35、96%。未污染的数据上同样差这么多，所以来自交叉拟合 DR 这一步而非清洗；n = 400–800 时覆盖回到 94–95%。
- **`sp.simex` 的渐近方差与 MC-SIMEX（2026-10-28 起）。** `variance='asymptotic'` 是 Carroll 等（1996）的估计方程方差，逐行按 R `simex(asymptotic=TRUE)` 的布局：朴素拟合与各 λ 下 B 次平均的得分堆成 `PSI`，雅可比块对角，经外推曲线做 delta 法。得分用似然得分 `w x (y-μ) d / v`，R 用 `x (y-μ)` 且忽略先验权重：无权重的最小二乘、logit、Poisson 两者相同，probit 与带权重时不同，R 的那个不是所拟合模型的得分。与 R 一样，异方差的误差标准差拒绝渐近方差（常数列可以）。`misclassification={'x': P}` 是 MC-SIMEX（Küchenhoff 等 2006，R `mcsimex`），P 的列是真值、每列和为 1，要求 `P00 + P11 > 1`；`P ** λ` 用特征分解并按 R `zapsmall` 舍到 7 位；被误分类的可以是 0/1 回归元或 0/1 结果变量，不与 `error_sd` 同用。新增外推曲线 `'loglinear'`（R `logl`，路径有非正值时平移 `|min| + 1`）。证据：两侧喂同一批伪误差与再误分类向量（R 侧替换 simex 导入环境里的 `rnorm` 与命名空间里的 `misclass`，Python 侧替换 `_pseudo_errors` / `_simex_misclass.misclassify`），确定性对齐：点估计与渐近 SE ≤ 8e-15；jackknife SE 最小二乘 8e-15、logit 1.7e-9（R `glm` 返回的协方差用的是最后一次更新前那一轮的权重，参考端已设 `epsilon = 1e-16`，默认 1e-8 时差 3e-5）；有理外推 2.9e-7（R `nls` 的停止准则）。未做：k > 2 类的误分类因子、两种误差同时存在的组合、R 的 `log2` 外推。
- **`sp.noisy_covariates` 的附录 E 估计量与作者代码对齐（2026-10-28 后续一轮）。** `elasticity`（E.4，字典 `(X, D X, D² X)`，矩 `(0, X, 2D X)`）、`policy_effect`（E.3，仿射反事实 `policy=`，可移动精确观测的 `treat`）、`partially_linear_iv`（E.6，连续工具，比值的 delta 方差与 LATE 相同）；代码在 `_noisy_functionals.py`。加权有两种口径：默认（回归不加权，只加权泛函）对部分线性类估计量的矩是常数，结果基本是不加权系数；`weighted_fit=True` 是作者复现代码的加权回归与加权 Riesz 表示（相当于 Stata `[aw=]`）。ADH 上两者分别是 −0.448 和 −0.618，不是 bug，是不同的投影；默认值随后改为按作者口径加权（见下文 `weighted_fit` 默认值一条）。证据：作者复现包（Zenodo 19866751，CC-BY-4.0，测试经 `_fetch.RemoteFile` 按 SHA-256 拉取，未缓存且未设 `STATSPAI_FETCH_DATASETS` 时跳过）的 `rrr_iv` 在 ADH 上与本实现同输入对齐：标准化协变量 1e-15，原始尺度 1e-11 到 3e-10（条件数，作者代码自身 Linux 与 macOS 之间差 1.8e-11）。论文已发表的含噪、隐私化各行是 R 单次抽样且未公开，只做 S 级筛查（20 次抽样，每行在 3 个 MC SD 内）。`policy_effect` 只在反事实留在低秩协变量的张成空间内时可识别；单独平移一列会离开该空间，结果取决于最小范数系数。`pd.read_stata` 读入的 float32 列要先转 float64 再标准化，否则误差在 1e-8 量级。仍未做：数据驱动的秩规则（论文看碎石图、代码固定 k = 5，没有规则可依）；E.7 异质效应与附录 F 非线性字典；`sp.datasets` 的 ADH 公共加载器。
- **`sp.simex` 多类误分类（2026-10-28 补完）。** k > 2 类的变量必须以因子进入公式（`C(x)` / `i.x` / 分类列）。数组矩阵按 0..k-1，DataFrame 按标签（行按列顺序重排）。每个模拟数据集按新的类别重建哑变量。有效性条件照搬 R `check.mc.matrix`：矩阵对数 zapsmall 后对角置 1，不得有小于 −eps 的元；特征值为复数或非正时拒绝。结果变量仍只允许 0/1、2×2，与 R 相同；与交互项同用时拒绝。二值路径逐字节不变（43 组配置）。证据：与 R `mcsimex` 同一批再误分类向量确定性对齐（`simex_det_factor_*`，独立随机流，旧夹具字节不变），点估计 4e-15、渐近与 jackknife SE 1.6e-14。
- **`sp.noisy_covariates` 的 `weighted_fit` 默认值（2026-10-28 改，未发布故不走弃用）。** `None` 即给了 `weights` 就加权拟合（作者口径），ADH 上不传参数即得 −0.61799。显式 `False` 是旧的投影（只加权泛函），ADH 上为 −0.448。
