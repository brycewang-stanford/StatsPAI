# 测量误差（回归元与协变量）

> 2026-10-28 随 Econometrica 94(5) 一轮新建。改动 `measurement_error/` 之前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`measurement_error/eivreg.py`（`sp.eivreg`，2026-10-28 起）**：与 Stata 18 `eivreg` 对到舍入（系数、标准误、F、R²、root MSE 差 5e-15，`tests/reference_parity/test_eivreg_stata_parity.py`，五个设计含 `[aw=]` / `[fw=]` / 零权重行）。公式见 [R] eivreg 的 Methods and formulas，三处容易写错、由 parity 测试钉住：(1) `S_jj = (1 - r_j)(N - 1) s_j^2`，`s_j^2` 是加权样本方差，`N` 是加权个数（aweight 先缩放到和为行数）；(2) 方差是 `A^{-1} H'WH A^{-1}`，**没有**小样本因子，aweight 下 `W` 取平方；(3) R² 是 `1 - (y'Wy - b'Ab)/TSS`，F 是斜率的 Wald 统计量除以斜率个数。权重为零的行退出样本（与 Stata `e(N)` 一致）。"信度太小"的判据是中心化 `[X, y]` 的修正二阶矩矩阵正定；单个误差变量时即 `r > R²(x 对其余回归元与 y)`，夹具上 Stata 的门槛在 0.4359 与 0.4360 之间，我们相同（解析下限 0.435934），越过时抛 `IdentificationFailure`（Stata 是 r(399)）。不带截距的模型和共线公式直接拒绝，不静默丢项。
- **`measurement_error/simex.py`（`sp.simex`，2026-10-28 起）**：已知误差标准差的加性正态误差，线性 / logit / probit / Poisson。抽样顺序是"每个 lambda（升序）× 每个复制 B，抽一个 `(n, 误差变量个数)` 的标准正态矩阵"，改顺序会改变固定种子下的所有数。每个 lambda 的 jackknife 方差是 `mean_b V_b - cov_b(theta_b)`（`ddof=1`），与 R `simex` 相同；朴素协方差对 GLM 取期望信息的逆（R `vcov.glm`），对最小二乘取经典式，`vce='robust'` 换成 HC0。R `simex` 的 `fitting.method="nonlinear"` 在系数路径近乎平坦时会在 `stats::nls` 里报错（屏幕夹具上就报了）；我们对该系数退回二次外推、告警并写入 `diagnostics['quadratic_fallback_terms']`，所以对 R 的筛查只覆盖二次和线性外推。`B` 沿用 R `simex` 与文献的名字（它是模拟次数，不是 bootstrap，所以不叫 `n_boot`）。GLM 拟合是 `simex.py` 里的私有 Fisher scoring（`mediation/_four_way_engine.fit_glm` 没有 probit 也不收权重）；以后有共用的 GLM 基元时迁过去。误差变量必须以原始列进入公式，同时出现在交互或变换里会被拒绝（扰动传不进那些项）。证据：已知真值（n = 20,000 时有理外推把线性斜率从 1.6 拉回 2，误差 0.04 以内）+ 恒等式（lambda = 0 等于 `sp.regress` / `sp.logit` / `sp.poisson`；误差为 0 恰为朴素估计量）+ 对 R `simex` 1.8 的 **S 级**筛查（8 个种子、间隔 `1000 + 100000k`，容差 5 个模拟差 SD，`tests/reference_parity/test_simex_r_screen.py`），不写成 parity。Stata 的 `simex` 不在 SSC 上，`net search` 找不到，没有 Stata 参考。
- **`measurement_error/noisy_covariates.py`（`sp.noisy_covariates`，2026-10-28 起，Agarwal-Singh 2026）**：按 arXiv v6 的算法（Econometrica 版是缩写）。训练折里缺失格填 0、观测格除以观测比例 `rho_j = max(观测均值, 1/m)`，对填充后的训练块做截断 SVD（复用 `matrix_completion._core._svt`，`theta=0`）；OLS 与平衡权重来自同一个伪逆 `P = pinv(B)`（`beta = P y`，`eta = P P' M`）；测试行只填充、**不投影**（论文的"隐式清洗"），不要"修"成也清洗测试行，那会破坏推断依赖的条件独立。常数项在清洗**之后**加（`add_constant=True`）：放进 SVD 里它的奇异值是 sqrt(m)，p 大时低于噪声底而被截掉；不加常数时 ATE 字典表示不了常数效应，论文自己的设计会给出 -0.27（真值 2.2）。`_pinv` 截断 `1e-9 * s_max` 以下的奇异值，numpy 默认容差会把精确低秩矩阵留下的 1e-15 级舍入奇异值也求逆。方差是 `mean(psi_centred^2)/n`（ddof 0，论文 Lemma D）；LATE 用 delta 方法得分 `(psi_Y - theta psi_D)/第一阶段`。`rank=None` 用 Gavish-Donoho 硬阈值（不在论文里，论文把秩当调参），有缺失时会多选（测试设计里真秩 3 选到约 12），论文说多选代价小、少选才有偏。折按处理组分层（LATE 按工具变量）。
  - **区间不覆盖的 1/p 阶偏差是真实的**：每个单位自身的噪声在保留的 k 个方向里仍在。Corollary 5.4 要求 `n^(2/3) <= p <= n^(3/2)`，`model_info["p_in_theory_range"]` 报告是否满足，但不告警，因为论文自己的 ADH 应用（n 约 1,444，p = 30）就在范围外。p = 30、n = 1,500、强混杂时部分线性估计 1.00，真值 0.70。
  - 论文自己的模拟设计（n = p = 100，秩 5，20% 噪声，k = 5）300 次重复：均值 2.24、平均 SE 0.38、覆盖 92%；论文报 2.22、0.35、96%。未污染的数据上同样差这么多，所以来自交叉拟合 DR 这一步而非清洗；n = 400–800 时覆盖回到 94–95%。
