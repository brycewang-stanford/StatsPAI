# 生存分析

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`survival/models.py`**：`sp.cox` 的稳健 / 聚类方差必须用**与 `ties=` 相同规则**的得分残差（`_cox_score_individual(breslow=)`）。1.39 前 Efron 拟合用的是 Breslow 残差，无并列时两者相同所以单元测试没抓到，并列多的数据上稳健 SE 偏 2%（⚠️ 已修）。约定：`robust='hc0'` 是裸三明治（= R `coxph(robust=TRUE)`；Stata `stcox, vce(robust)` 再乘 `N/(N-1)`），`cluster=` 带 `G/(G-1)`（= Stata；R 不带）。`sp.kaplan_meier(conf_type=)` 的默认值正在走弃用流程：1.39 不传时仍是 `'plain'` 并发 `DeprecationWarning`，**1.40 改为 `'log-log'`**（Stata `sts` 的默认；R `survfit` 是 `'log'`）；改默认时同步 MIGRATION 与文档里的调用（现已全部显式写出 `conf_type`）。
- **加权与计数过程（2026-10-19 起）**：`sp.cox(weights=, start=)` 与 R `coxph` 同一口径：风险集求和 `w_k exp(x_k'b)`，Efron 每个事件时刻的 `d` 项各乘该时刻死亡者的**平均权重**，`l/d` 的下调比例仍按死亡**人数**计（不是权重和）。`start=` 是 `(start, stop]`：`start < t <= stop` 才在风险集里，`start == t` 不算（R `agreg` 同）。零权重行在拟合前删除，不计入 `N`（Stata `[pw=]` 同，`N/(N-1)` 依此）。稳健方差的得分残差本身不加权，三明治里乘 `w_i`。`ssc=None` 保留历史口径（稳健无因子、聚类 `G/(G-1)`），`'r'` 全无因子，`'stata'` 稳健 `N/(N-1)`、聚类 `G/(G-1)`；**不要改默认**，翻译器显式写 `ssc`。Stata 不允许 `[pw=]` 配 `efron`（r(101)），翻译器同样拒绝；`stset ..., id()` 下 `stcox, vce(robust)` 按 id 聚类。`ph_test` 尚不支持加权 / 计数过程拟合，直接拒绝；R `cox.zph` 支持，属未决项。
- **加权 KM**：`sp.kaplan_meier(weights=, start=, cluster=, se_method=)`；`se_method=None` 跟随 R `survfit` 规则（有 `cluster` 或非整数权重 → IJ 稳健方差，否则 Greenwood）。注意 R `survfit` 对象里稳健方差时 `$std.err` 的尺度与 Greenwood 时不同（前者已是 `S` 尺度），对照时用 `summary(fit)$std.err`。
- **`sp.stteffects`（`survival/teffects.py`，2026-10-19 起）**：Stata `stteffects` 的堆叠估计方程。点估计逐块求解（删失模型 → 处理模型 → 每臂结果模型 → POM），方差是 `A^-1 B A^-T / N`，`A` 用解析矩条件的中心差分。参数化与 Stata 相同：Weibull `lambda = exp(-xb)`、`s = exp(eta)`，均值 `exp(xb) Gamma(1+1/s)`（AFT 度量，`b` 越大时间越长）。**已知偏离**：Stata `stteffects ipwra, atet`（LAC 与 WAC 都是）把用 ATET 权重拟合的结果模型的预测值在**全样本**上平均（手册式 15e–15f 没有处理指示），在结果模型正确时估的是 ATE；我们在处理组上平均（与 Stata 自己的 RA / IPW ATET 一致）。测试里用我们的系数在全样本上平均可逐位复现 Stata 的数，并有异质效应 DGP 的已知真值检验。RA / IPW 的 ATET 两边一致。未实现：带协变量的 ancillary 方程、多值处理、gamma 分布、延迟进入（Stata 也不允许）。
- **`sp.rmst`**：无权重时与 `survRM2::rmst2` 一致（含 RMST / RMTL 比值的对数尺度区间）；有权重时用 IJ 方差（R `residuals(survfit, type="rmst")`，权重视为固定）。注意 R 的 `summary(survfit, rmean=)` 在有权重时报的是**加权计数上的 Greenwood 型** `se(rmean)`，IPTW 权重和远大于 `n` 时会显著偏小，不要拿它当参考。无权重时 IJ 与 Greenwood 型 RMST 方差恰好相等（有测试）。`se_method='xie_liu'` 只用于曲线（`adjustedCurves` 的口径），不用于面积。
- **`sp.msm(censor=)`（`msm/_censoring.py`）**：人-期数据，`censor=1` 标在单位被删失的那一期（该行结局不可观测，必须是该单位最后一行；之后不能再有行），删失模型用所有在险行的 pooled logit，分子 `[lag(A), V]`、分母再加 `censor_covariates`（默认 `time_varying`），逐期比值累乘，对应 R `ipwtm(exposure = cens, family = "binomial", type = "first")`。被删失的行必须带着删失模型的协变量（`L`），缺了直接报错，不静默丢行。`trim` 作用于处理权重 × 删失权重的乘积。`sp.ipcw` 的 `pooled_logistic` 是逐行的完整病例 IPW、不做累乘，不适用于人-期数据，所以没有复用它。
- **`sp.cox(design=)` / `sp.kaplan_meier(design=)` / `sp.msm(design=)`**：`design=`（复杂抽样设计，2026-10-19 起）只有一个方差入口：`survey/linearization.py::design_vcov`（= R `survey::svyrecvar`，含 strata / PSU / fpc / lonely-PSU / 校准），估计器只负责交出逐行贡献 `u_i`（`theta_hat - theta ≈ Σ u_i`，抽样权重已在里面；对均值归一的权重就是 `u/n`）。不要在估计器里再写一份 PSU 求和或 `G/(G-1)`。`design=None` 时代码路径与之前逐位相同；`design=` 与 `weights=` / `cluster=` / bootstrap 同用一律报 `MethodIncompatibility`。推断用 t(#PSU − #strata)（Stata `svy` 口径）。证据在 `tests/reference_parity/test_survey_causal_parity.py` / `test_survey_did_parity.py`（R survey 4.5，1e-14 量级）。 Cox 等于 R `svycoxph`（Efron 并列）。KM 的参照**不是** `svykm(se=TRUE)`（夹具上它的曲线与乘积极限估计差到 0.019，`se=FALSE` 时才与 survfit 一致到 2e-15；只看输出得出，survey 是 GPL，不读源码），而是 `resid(survfit, type='surv')` 的 IJ 影响乘权重再 `svyrecvar`；KM 把各 PSU 的影响总和放到该 PSU 的一行上算方差，所以拒绝校准设计。MSM 走 R `ipw::ipwtm` + `svyglm` 的做法：处理 / 删失模型不加权，结果模型权重 = 设计权重 × 稳定化权重，IP 权重视为已知。
