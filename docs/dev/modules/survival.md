# 生存分析

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`survival/models.py`**：`sp.cox` 的稳健 / 聚类方差必须用**与 `ties=` 相同规则**的得分残差（`_cox_score_individual(breslow=)`）。1.39 前 Efron 拟合用的是 Breslow 残差，无并列时两者相同所以单元测试没抓到，并列多的数据上稳健 SE 偏 2%（⚠️ 已修）。约定：`robust='hc0'` 是裸三明治（= R `coxph(robust=TRUE)`；Stata `stcox, vce(robust)` 再乘 `N/(N-1)`），`cluster=` 带 `G/(G-1)`（= Stata；R 不带）。`sp.kaplan_meier(conf_type=)` 的默认值 **1.40 起是 `'log-log'`**（Stata `sts` 的默认；R `survfit` 是 `'log'`；1.39 及以前是 `'plain'`，弃用告警已删）；文档里的调用仍全部显式写出 `conf_type`。
- **加权与计数过程（2026-10-19 起）**：`sp.cox(weights=, start=)` 与 R `coxph` 同一口径：风险集求和 `w_k exp(x_k'b)`，Efron 每个事件时刻的 `d` 项各乘该时刻死亡者的**平均权重**，`l/d` 的下调比例仍按死亡**人数**计（不是权重和）。`start=` 是 `(start, stop]`：`start < t <= stop` 才在风险集里，`start == t` 不算（R `agreg` 同）。零权重行在拟合前删除，不计入 `N`（Stata `[pw=]` 同，`N/(N-1)` 依此）。稳健方差的得分残差本身不加权，三明治里乘 `w_i`。`ssc=None` 保留历史口径（稳健无因子、聚类 `G/(G-1)`），`'r'` 全无因子，`'stata'` 稳健 `N/(N-1)`、聚类 `G/(G-1)`；**不要改默认**，翻译器显式写 `ssc`。Stata 不允许 `[pw=]` 配 `efron`（r(101)），翻译器同样拒绝；`stset ..., id()` 下 `stcox, vce(robust)` 按 id 聚类。`ph_test` 对加权 / 计数过程拟合给出 `cox.zph` 的得分检验（2026-10-20 起，`test_cox_zph_weighted_parity.py`，14 个拟合 × 4 种变换，相对 1e-6）：权重进入得分与信息阵的方式与偏似然相同，信息阵永远是模型型的（`robust=` / `cluster=` 不影响，R 输出亦然）；时间变换**不加权**（`km` 是 `(start, stop]` 数据的不加权 KM，`rank` 按所有行的终止时间排秩），都是从 `cox.zph` 的 `$x` 输出读出的。`method='approx'` 仍只对不加权的右删失拟合；`design=` 拟合拒绝。
- **加权 KM**：`sp.kaplan_meier(weights=, start=, cluster=, se_method=)`；`se_method=None` 跟随 R `survfit` 规则（有 `cluster` 或非整数权重 → IJ 稳健方差，否则 Greenwood）。注意 R `survfit` 对象里稳健方差时 `$std.err` 的尺度与 Greenwood 时不同（前者已是 `S` 尺度），对照时用 `summary(fit)$std.err`。
- **`sp.stteffects`（`survival/teffects.py`，2026-10-19 起）**：Stata `stteffects` 的堆叠估计方程。点估计逐块求解（删失模型 → 处理模型 → 每臂结果模型 → POM），方差是 `A^-1 B A^-T / N`，`A` 用解析矩条件的中心差分。参数化与 Stata 相同：Weibull `lambda = exp(-xb)`、`s = exp(eta)`，均值 `exp(xb) Gamma(1+1/s)`（AFT 度量，`b` 越大时间越长）。**已知偏离**：Stata `stteffects ipwra, atet`（LAC 与 WAC 都是）把用 ATET 权重拟合的结果模型的预测值在**全样本**上平均（手册式 15e–15f 没有处理指示），在结果模型正确时估的是 ATE；我们在处理组上平均（与 Stata 自己的 RA / IPW ATET 一致）。测试里用我们的系数在全样本上平均可逐位复现 Stata 的数，并有异质效应 DGP 的已知真值检验。RA / IPW 的 ATET 两边一致。未实现：带协变量的 ancillary 方程、多值处理、gamma 分布、延迟进入（Stata 也不允许）。
- **`sp.rmst`**：无权重时与 `survRM2::rmst2` 一致（含 RMST / RMTL 比值的对数尺度区间）；有权重时用 IJ 方差（R `residuals(survfit, type="rmst")`，权重视为固定）。注意 R 的 `summary(survfit, rmean=)` 在有权重时报的是**加权计数上的 Greenwood 型** `se(rmean)`，IPTW 权重和远大于 `n` 时会显著偏小，不要拿它当参考。无权重时 IJ 与 Greenwood 型 RMST 方差恰好相等（有测试）。`se_method='xie_liu'` 只用于曲线（`adjustedCurves` 的口径），不用于面积。
- **`sp.msm(censor=)`（`msm/_censoring.py`）**：人-期数据，`censor=1` 标在单位被删失的那一期（该行结局不可观测，必须是该单位最后一行；之后不能再有行），删失模型用所有在险行的 pooled logit，分子 `[lag(A), V]`、分母再加 `censor_covariates`（默认 `time_varying`），逐期比值累乘，对应 R `ipwtm(exposure = cens, family = "binomial", type = "first")`。被删失的行必须带着删失模型的协变量（`L`），缺了直接报错，不静默丢行。`trim` 作用于处理权重 × 删失权重的乘积。`sp.ipcw` 的 `pooled_logistic` 是逐行的完整病例 IPW、不做累乘，不适用于人-期数据，所以没有复用它。
- **`sp.cox(design=)` / `sp.kaplan_meier(design=)` / `sp.msm(design=)`**：`design=`（复杂抽样设计，2026-10-19 起）只有一个方差入口：`survey/linearization.py::design_vcov`（= R `survey::svyrecvar`，含 strata / PSU / fpc / lonely-PSU / 校准），估计器只负责交出逐行贡献 `u_i`（`theta_hat - theta ≈ Σ u_i`，抽样权重已在里面；对均值归一的权重就是 `u/n`）。不要在估计器里再写一份 PSU 求和或 `G/(G-1)`。`design=None` 时代码路径与之前逐位相同；`design=` 与 `weights=` / `cluster=` / bootstrap 同用一律报 `MethodIncompatibility`。推断用 t(#PSU − #strata)（Stata `svy` 口径）。证据在 `tests/reference_parity/test_survey_causal_parity.py` / `test_survey_did_parity.py`（R survey 4.5，1e-14 量级）。 Cox 等于 R `svycoxph`（Efron 并列）。KM 的参照**不是** `svykm(se=TRUE)`（夹具上它的曲线与乘积极限估计差到 0.019，`se=FALSE` 时才与 survfit 一致到 2e-15；只看输出得出，survey 是 GPL，不读源码），而是 `resid(survfit, type='surv')` 的 IJ 影响乘权重再 `svyrecvar`；KM 把各 PSU 的影响总和放到该 PSU 的一行上算方差，所以拒绝校准设计。MSM 走 R `ipw::ipwtm` + `svyglm` 的做法：处理 / 删失模型不加权，结果模型权重 = 设计权重 × 稳定化权重，IP 权重视为已知。 **复制权重设计**（2026-10-20 起）：`sp.cox(design=svrepdesign)` 逐复制重拟合，零权重行删除（= Stata `[pw=]`）。R `svycoxph` 的复制拟合保留被删行、给极小权重，Efron 的 `l/d` 按死亡**人数**计，所以 Efron 下 SE 与 R 差约 3e-4（Breslow 一致到 1e-8）；测试用 1e-10 权重重算复现了 R 的数，机制已证实，不要为了对齐而改成保留零权重行。`kaplan_meier` / `msm` 拒绝复制设计。
- **`sp.finegray(weights=)`（2026-10-19 起）**：与 Stata `stcrreg` + `stset [pw=]` 同一口径——删失 KM（Ĝ）也加权、风险集与事件数加权、稳健方差用加权得分残差（含估计 Ĝ 的那一项），权重先归一到均值 1（对数伪似然因此等于 Stata 的）。Stata 带 `n/(n-1)`，对应 `small_sample=True`；默认 `False`（cmprsk `crr` 口径，但 crr 本身不支持权重）。`vce='model'` 在有权重时拒绝。证据 `tests/reference_parity/test_finegray_weighted_stata_parity.py`，按输出对齐（1e-6，Stata 只迭代三步）。
- **`sp.cox(tvc=, texp=)`（`survival/_cox_tvc.py`，2026-10-28 起）**：Stata `stcox, tvc() texp()`。做法是精确拆分：每行的 `(start, stop]` 在**本层**落在区间内部的失败时刻处切开，每段带 `z*g(段末)`，再走 `start=` 的计数过程风险集；Efron / Breslow、权重、分层、延迟进入因此都不用另写。稳健方差以**输入行**为单位（先把同一行各段的得分残差加总，`N/(N-1)` 的 `N` 是输入行数，= Stata；R `coxph(tt=)` 的 `cluster=id` 无因子，对应 `ssc=r`）。主方程系数保持原名，时变系数命名为 `tvc:z`（Stata 的 `tvc` 方程）。`texp` 字符串由封闭文法解析（`_t`、数字、`+ - * / ^`、比较、括号、`ln log log10 exp sqrt abs min max`；一元负号低于 `^`，`a^b^c` 拒绝；**不许** `eval`），也可传可调用对象；只要求在失败时刻有限。拆分行数 = 输入行 + 各行区间内的失败时刻数，超过 `MAX_EPISODES`（1e8）拒绝并提示把时间粗化。`ph_test()` 对 tvc 拟合拒绝（R `cox.zph` 对 `tt()` 同样拒绝）；`design=` 拒绝。证据 `tests/reference_parity/test_cox_tvc_parity.py`：Stata 18 十个设定（两种并列规则、五种 texp、稳健 / 聚类 / pw / 分层 / 延迟进入）系数与 SE 相对差 ≤ 3.3e-7（最差那格我们的对数似然更大，是 Stata 的停止点），R `coxph(tt=)` 六个设定 ≤ 2.5e-8（那一格是 R 的收敛容差，其余 ≤ 5e-13）。未决（与 tvc 无关、早已存在）：`[pw=]` 拟合报告的 `Log-likelihood` 与 Stata `e(ll)` 不是同一个数（同一份数据不带 tvc：-3664.24 对 -2348.95），系数与 SE 一致。
- **`sp.cox` 的 Newton 循环（2026-10-28 起）**：先算 Newton 步，步长 `< 1e-9` 即判收敛且**不走这一步**（R `coxph` 也停在这里，所以加权 / 计数过程的 R parity 仍是 ~1e-15，不要改成"走完再判"）；更大的步，线搜索接受"似然在舍入范围内不下降"（`<= nll + 1e-12*max(1,|nll|)`）。此前要求下降 1e-10，1e-9 到 1e-6 的步会让线搜索耗尽，衰减 2^-20 后的步又通过了收敛判据，于是停在差一步的地方（模拟的 800 次拟合里 436 次，最多 5.8e-7；Linux / numpy 2.2 上 tvc 与 Stata 差 4e-6）。新估计器里的步长减半循环同样不要拿衰减后的步判收敛（⚠️ 已修）。证据 `tests/test_cox_newton_convergence.py`（得分方程）。`svycoxph` 的 jk1 一格差 1.1e-9：R 停下时还剩 1.08e-9 的 Newton 步，我们的剩 2e-16。
- **2026-11-13 流行病学盲测一轮（`tests/reference_parity/test_probe_epi_parity.py`）**：(1) `baseline_hazard()` 跟随拟合的并列规则：Efron 拟合用 Efron 增量 `sum_{l<d} wbar / (S0 - (l/d) D0)`（`CoxKernel.baseline_increments`，与偏似然同一组项），= R `basehaz(centered=FALSE)` 与 Stata `predict, basechazard`；此前 Efron 拟合报的是 Breslow 增量（⚠️ 已修）。带权、分层、延迟进入四种设定对 R 到 1e-8。分层拟合的表带 `strata` 列、每层自带 `time = 0` 行，**不要**再把各层首尾相接成一张无标签的表。(2) 分层拟合的一致性指数只数层内的对（`risk_set_concordance(strata=)`）；无权重、无 `start=` 的分层拟合此前走了不看层的 `harrell_c`（⚠️ 已修，lung 按性别分层 0.6097 → 0.6058 = R / Stata）。(3) `sp.rmst` 的默认 `tau` 是 `rmst2` 的规则（黑箱核对四种情形）：最后一个观测被删失的组把 `tau` 封顶在该组最大时间，最后一个观测是事件的组不封顶（曲线已到 0）；所有组都以事件结束时取最大时间。并列在最大时间上只要有一行删失就算删失。Greenwood 与 IJ 方差在曲线到 0 之后的那一项为零，无需特判。(4) `KMResult.quantiles` 的置信限是置信带穿过 `1 - p` 的时刻（R `quantile(survfit)`），估计值本身沿用 Stata 的"首个 `S(t) <= 1 - p`"规则（R 在台阶恰等于 `1 - p` 时取中点），两者只在那种台阶上不同。(5) `sp.logrank_test(rho=)` 的权重是**左连续**的合并样本 KM `S(t-)^rho`（分层时取层内 KM），`rho != 0` 时返回的观测 / 期望数是加权的（`survdiff` 的打印值）。(6) `CoxResult.summary()` 在系数表后打印风险比表；它是在基类 `summary()` 的文本上插入的，没有改 `core/results.py`（改那个文件要重录全部 Track A trace）。未做：`ties='exact'`、AFT 的稳健 / 聚类方差、`estat phtest` 之外的图形诊断。
- **2026-11-13 缺口补齐（`tests/reference_parity/test_gaps_epi_parity.py`）**：(1) `sp.cox(ties='exact')`（`survival/_cox_exact.py`）是精确偏似然：每个并列时刻的分母是风险集风险得分的 `d` 阶初等对称多项式，按 `e_j(1..i) = e_j(1..i-1) + r_i e_{j-1}(1..i-1)` 逐阶用累加求得（连同一、二阶导数），每个时刻 `O(|R| d p^2)`；单一失败的时刻仍走普通内核。对 R `coxph(ties='exact')` 与 Stata `stcox, exactp`（含分层、延迟进入）到 1e-11。**不接受** `weights=` / `robust=` / `cluster=` / `design=`（R 与 Stata 同样拒绝），`ph_test()` 拒绝（精确似然没有 Schoenfeld 残差；R `cox.zph` 给出的数无法从文档复现，不照抄）。基线风险沿用 R `basehaz` 的做法：在精确估计处取 Breslow 增量；Stata `predict, basechazard` 在 `exactp` 之后是另一个估计量（第 18 周 0.151 对 0.204），不跟。延迟进入的精确似然 R 的 `agexact` 是枚举子集，本数据上跑不完，所以该情形只有 Stata 作参考。工作量超过 `MAX_EXACT_WORK` 时拒绝并建议 `efron`。(2) `sp.aft(robust=, cluster=)` 只是把参数转给 `sp.survreg`：`'robust'` 带 Stata 的 `N/(N-1)`，聚类带 `G/(G-1)`，R `survreg(robust=TRUE)` / `cluster=` 不带因子（测试里乘回去对上）。稳健 SE 与两个参考都差约 4e-7 到 7e-7，而 R 与 Stata 彼此一致到 1e-12：`ml_newton_polish` 的 Hessian 是精确得分的有限差分（观测信息 SE 本身差 1.2e-7），三明治把它用了两次。测试容差 2e-6 并写明机制；要收紧得把 `regression/_optim_helpers.ml_scores_hessian` 换成解析 Hessian，那会让所有用它的估计量在 1e-7 量级变数，未做。
