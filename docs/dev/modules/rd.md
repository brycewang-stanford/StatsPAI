# 回归断点（RD）

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`rd/`**：kernel / 局部多项式 / sandwich 走 `rd/_core.py`，不要重新实现。
- **`rd/optimized.py`（`sp.rd_optimized`，Imbens-Wager 2019）**：权重必须**精确**满足四个矩条件（两侧各自和为 ±1、与 running variable 正交，`_project`），否则最坏偏差无界；报告的 `max_bias` 是对*实际使用的权重*按 `M·∫|G|` 精确积分得到的（`worst_case_bias`），不是优化问题里离散化后的那个数——对任何权重都成立，对局部线性权重退化成 RDHonest 的闭式。求解用「单位跳跃、曲率 ≤ kappa 的最不利函数」的有界最小二乘（scipy `lsq_linear(method='bvls')`），再对 kappa 做一维搜索；**不要**换成乘子形式上的 L-BFGS-B 或自写的投影牛顿：Hessian 是二次积分算子，条件数太差，两者都试过、都不收敛。与 `optrdd` 是同一规划的两种离散化，只能对到约 0.01 个标准误（估计）和 0.3%（偏差），按 S 记，不要写成 parity；optrdd 的权重对 running variable 的正交只到 5e-5。连续 running variable 下相对 `sp.rd_honest` 的增益只有千分之几（三角核本来就接近最优），不要在文档里夸大。`fuzzy=` 用结果方程选出的同一组权重，区间是 Anderson-Rubin 式的集合 `{t: |γ'(Y − tD)| ≤ cv·se(t)}`，偏差界为 `(M + |t|·M_fuzzy)·∫|G|`；弱第一阶段时区间无界是正确行为，不要改成 delta 法区间。完全依从时必须精确退化为 sharp 结果（测试守着）。二维 running variable 没做：需要一般线性不等式约束的 QP，scipy 没有合适的求解器。
- **`rdrobust.py::_parse_data` 不得对 `covs` 去均值（2026-10-19）**：fuzzy 带宽级联在 `nu = 0` 用两侧在断点处的*水平* `tau_Y / tau_T` 构造 delta 法权重，水平随协变量的位置而变；去均值让 fuzzy + covs 的 mserd `h` 与 rdrobust 4.0.0 差 4e-3 到 5e-3（`b`、sharp 带宽和固定 `h` 的估计都不受影响）。旧 fuzzy fixture 的协变量是标准化的，所以没发现；`test_rd_fuzzy_covs_level_R_parity.py` 用均值非零的协变量守着。
- **`rdrobust` / `rdbwselect` 的聚类方差跟 R rdrobust 4.0.0（2026-10-21）**：有 `cluster=` 时 `nn` / `hc0` / `hc1` / `cr1` 是 CR1，`hc2` / `cr2` 是 CR2，`hc3` / `cr3` 是 CR3（R 的映射，`hc2` / `hc3` 时发 `StatsPAIWarning`）；`cr*` 不带 `cluster=` 退回 `hc*` 并警告，同 R。CR2 / CR3 是每个簇的残差乘 `(I - H_gg)^(-1/2)` / `(I - H_gg)^(-1)`，`H_gg` 是**同一个拟合**的加权帽子矩阵的簇块（常规方差用 `p` 阶 `h` 拟合，稳健方差用 `q` 阶 `b` 拟合），不乘小样本因子；`h > b` 时并集窗口里 `b` 拟合权重为零的行也要按非对称 `H_gg` 的那一块补上（`rd/_cct_side.py::cluster_adjusted_residuals` 的闭式），否则稳健 SE 差 1e-8。带宽级联用同一套方差，所以 `h` 也跟着变。旧做法（HC2 / HC3 缩放的残差 + CR1 因子）在 `rd_covs_discriminating` 上比 R 小 7%（CR2）到 18%（CR3），属 ⚠️ correctness。对齐 1e-9（`test_rd_cluster_cr23_R_parity.py`，CR2 且 `h > b` 的稳健 SE 一格 1e-8：那里的逆平方根病态，我们的闭式与 scipy `sqrtm` 都满足 `A A (I-H) = I` 到 5e-15 却相差 1e-9）。
- **`rddensity` 统计量不可算时报 NaN（2026-10-21）**：窗口内不同取值少于 `p + 2` 个或标准误为零时，`T` 与 p 值为 NaN、发 `AssumptionWarning`、`model_info['diagnostics']['not_computable']` 写明两侧有效观测数，同 R `rddensity` 2.6 的 `NA`。此前报 `T = 0, p = 1`（"无操纵证据"），是静默的错答。
- **`rdplot` 两处与 R 4.0.0 的有意差异，记 T4（2026-10-21 owner 委托人决定保留）**：(1) 边界分箱：等距分箱的 `lo + J d` 舍入到比 `max X` 小一步时，R 把最大的观测放进一个多出来的右侧分箱（其 `min/max/mean_bin` 为缺失），我们按论文把最后一个分箱在 `max X` 处闭合；R 的那个分箱是浮点舍入的产物，不是方法的一部分，平价测试把 R 的溢出行并进最后一个分箱比较。(2) 一侧结果为常数时（`v = 0` 或没有正的 `V`），R 报 `J_IMSE = Inf`、`J_MV = NaN`，我们报 `J_IMSE = J_MV = 1`；两边都发同样的警告、都只用一个分箱，画出的图相同，差别只在报告的"最优分箱数"上。保留 1 是因为它是实际使用的分箱数，元组保持整数（`tests/test_core_degenerate_inputs.py` 守着），不要改成 Inf / NaN。细节见 `docs/dev/cleanroom/rdplot.md`。
