# 双重差分与事件研究

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`did/did_forest.py`**：每个 (g, t) 一片森林，干净对照组规则与 CS 相同；聚合 SE 由单元级影响函数跨格求和。
- **`callaway_santanna(notyet_cutoff=)`**：默认 `'period'` 跟 R `did`（`G > max(t, base) + anticipation`）；`'asinr'` 是 Stata `csdid, asinr`（`G > t`），`'cohort'` 是 csdid 默认。三者只在 universal 基期的前期格或 `anticipation > 0` 时分歧，不要再把 asinr 写成"R 约定"。
- **`did/es_inference.py`**：`sp.event_study_vcov` 是**所有**事件研究估计量联合协方差的单一入口（CS/aggte、event_study、SA、Gardner、BJS、stacked、LP-DiD、dCDH、ETWFE），`sp.uniform_bands` 在其上做 sup-t 同时置信带，`honest_did` 的 FLCI 也走它。新增事件研究估计器时把联合协方差放进 `model_info['event_study_vcov']`（DataFrame，index/columns = 相对时间；只有确实拿不到前后期交叉协方差时才设 `attrs['block_diagonal']=True`，抽取器据此报 `joint=False`），抽取器会自动接上。**不要**再各自重建协方差：main 上曾用固定份额重建，非对角块与 R `did` 差 8%，FLCI 因此偏窄。
- **CS 的聚类变量**：面板上必须在单位内不变（`allow_unbalanced_panel=True` 也一样，2026-10-10 前这个开关会跳过检查，平衡面板上返回 1e-16 的标准误）。`panel=False` 时拒绝「在每个 cohort × 时期格内恒定」的聚类变量（时期本身、cohort 本身）：ATT(g,t) 的影响函数在处理组的格内求和为零，对 never-treated 比较组聚类标准误恰为零，对 not-yet-treated 是不聚类时的约 2%。源码里的报错信息仍写 "identically zero"，对后一种情况不准确；该文件在 Track C 计时路径上，下次因别的原因改它时顺手改掉。
- **`did/_arp_sets.py::rm_confidence_set`**：默认网格跟 `HonestDiD`，以 0 为中心、±20 个标准误。估计值 |t| > 20 时整个网格不含它，旧代码返回空集，`breakdown_m(method='relative_magnitude')` 于是对最显著的效应报 0。现在只在「什么都没接受且估计值在网格外」时把网格移到估计值两侧，其余结果不变。**不要**把默认网格改成以估计值为中心：那会改掉所有与 R 对齐的数。
- **`sp.drdid` 的面板路径**：权重取自处理前那一行（每单位一个，`DRDID` 的约定）。带权重的 `method='imp'` 复用 `callaway_santanna._dr_imp_att`，不带权重的仍走 `_drdid_imp_panel_core`（两者在无权重时是同一个估计量，保留后者是为了不动已提交的数）。四种估计方法与 `DRDID` 1.3.0 `weightsname=` 对到 1e-9。
- **`sp.did_multiplegt`**：没有可比格的安慰剂 / 动态效应是 NaN 并告警，不是 0；bootstrap 里没有可比格的重复不计入标准误。
- **`did/few_treated.py`**：处理组极少时（1 个或几个簇）簇稳健 SE 会大幅过度拒绝（实测 30 簇 AR(1) 设计上名义 5% 实际 74%）。`sp.did_few_treated` 用对照组构造安慰剂分布并反演，`method='ferman_pinto'` 额外按 `Var(W)=A+B/M` 校正组规模异方差（拟合为负时退 NNLS 并警告）。点估计仍是 TWFE 系数，**不声称一致**。
- **dCDH 家族（`did/did_multiplegt.py` / `did_multiplegt_dyn.py` / `twowayfeweights.py`）**：处理变量可以是离散非二值的（报纸数、税率档），三者都按**期初处理水平**匹配对照。`sp.did_multiplegt` 的 DID_M 是每单位处理的效应：每个切换者带自己变化的符号，除以总绝对变化量（2026-10 前把基线非 0 的切换者一律当 switch-off、不除变化量，在 Gentzkow 报纸面板上给出 −0.00082，`did_multiplegt_old` 是 0.0057791）。`sp.did_multiplegt_dyn` 内部把时期换成**秩**（`_tidx`，四年一期的面板等同年度面板）、丢掉已同时高于和低于期初水平的 (g,t)（Design Restriction 2）、事件按 (F, 方向, 期初水平) 划分、切换者方差单元按 (期初水平, F, F 期处理值) 中心化；`se_method='analytic'` 时联合检验直接用解析协方差做 Wald，不再跑 bootstrap；`aggregation='switchers'` 是 `Av_tot_eff`（Σ N_l δ_l / Σ N_l δ^D_l）；`same_switchers` 要求每个 horizon 的效应都**可估计**（有对照），不只是被观测到。**与 Stata 的一处有意不同**：非平衡面板上参考实现会因中间某期缺对照而把一个尚未切换的组整个删掉（它切换后的处理均值恰好回到期初水平时），我们保留它作对照；把该组从输入里删掉即可逐位复现 Stata（模块 docstring 与 `docs/dev/2026-10-05-dcdh-did-textbook-review.md`），不要为了对上而复制这个行为。`controls=` 的回归按期初水平（及 `trends_nonparam` 单元）在尚未切换的 (g,t) 上加权拟合，调整后的结果变量以**水平**形式写出（`Y − Xθ_d − Σλ`，面板有缺口也成立），解析方差带斜率估计项（`_residualise_on_controls` 返回的 `b`，事件上累加的 `m_x`），六种设定与 Stata 对到 5e-7。`placebo_sign='r'` 才是不带 `robust_dynamic` 的 `did_multiplegt_old` 的符号，默认 `'stata'` 是带 `robust_dynamic` 的。证据在 `tests/reference_parity/test_dcdh_textbook_stata_parity.py`（合成面板 + 162 个 Stata 数）。
- **`sp.sun_abraham`**：交互权重是各队列在该相对时间的**观测份额**（加权时是权重份额），不是单位份额——只有平衡面板上两者相等，非平衡面板必须用前者才与 `eventstudyinteract` 一致。`event_window` 默认只决定**报告**哪些相对时间（`window_rule='report'`，回归仍对全部相对时间饱和）；`'bin'` 把窗口外的相对时间并入端点；`'reference'` 是旧行为（窗口外的已处理观测进入参照组，系数被它们的效应污染），只为复现旧数字保留。
- **DiD 的日期型时间列（`did/_core.py::calendar_time_aware`）**：`callaway_santanna` / `sun_abraham` / `did_imputation` / `etwfe` / `gardner_did` / `stacked_did` / `wooldridge_did` / `twfe_decomposition` / `bacon_decomposition` / `did_forest` 接受 `datetime64` / `Period` 的时间列与 cohort 列，按观测到的日期顺序编号为 1..P，缺失或晚于样本末期的 cohort 记为 0（never treated），编号存 `model_info['calendar_time']`。新增 staggered 估计器时用同一个装饰器，并加一条「日期与整数编码结果相等」的测试：`gardner_did` 接入前在日期型面板上静默返回 3.13（整数编码为 1.93）。面板路径上 `callaway_santanna` 拒绝重复的 (unit, period) 行（旧代码 `aggfunc="first"` 静默取每格第一行，`sp.did(..., time='post')` 在日度数据上符号都反了）。
- **`sp.honest_did` 与 varying 基期**：`callaway_santanna(base_period='varying')` 的前期系数是逐期变化，不是相对参照期的前趋势路径，Rambachan-Roth 的两类约束不适用。传入时告警，并在返回表上写 `attrs['base_period']='varying'`（2026-10-18 起）；`sp.aggte` 把 `base_period` 带进自己的 `model_info`，所以聚合后的事件研究也查得到。没有拒绝，是为了不打断已有调用；新增以 CS 为输入的敏感性工具时同样检查这一项。
- **staggered 估计器的共用输入检查（`did/_validate.py`，2026-10-19 起）**：`callaway_santanna`（面板）/ `sun_abraham` / `did_imputation` / `gardner_did` / `stacked_did` / `etwfe`（面板）都调用同一组检查。cohort 列在单位内取多个值一律拒绝（R `did` 同样报错；NaN / inf / 0 都算 never treated，不算不同值）。重复的 (unit, period) 行：CS 拒绝，回归类估计量保留并发 `RepeatedUnitPeriodWarning`（`i` 可以是州这类组，组内每期有多个个体，Stata `did_imputation` 和 fixest 都接受）。处理簇少于 10 个时发 `AssumptionWarning`（与 CS 同一阈值）。**第一期即已处理的 cohort 各估计量处理方式不同，是有意的**：CS 丢掉没有基期的格并告警，BJS 默认拒绝、`autosample=True` 才丢（Stata 的做法），`gardner_did` 丢掉不可识别的已处理行，`sun_abraham` / `etwfe` / `stacked_did` 丢掉整个 cohort 并告警。`sun_abraham` 的规则更一般：在参照期（`ref_p`，默认 `-1 - anticipation`）没有任何一行的 cohort 都丢，因为它的交互项之和等于它自己的固定效应。fixest 不丢，而是删一个共线格，这会通过时期效应改动其他 cohort 的估计（审计面板上 t::-7 从 -0.18 变成 +0.57），所以 parity 参照是 fixest 在去掉该 cohort 的面板上的结果（`tests/reference_parity/test_did_validation_parity.py`）。
- **`sun_abraham` 的 headline**：默认 `.estimate` 是事后各相对时间效应的等权平均，不是 fixest 的 `summary(agg = "att")`（按 cohort × 时期格的大小加权）；后者是 `aggregation='fixest_att'`，并始终在 `model_info['att_fixest_att']`。`model_info['headline']` / `['other_aggregation']` 写明当前是哪一个并给出另一个（2026-10-19 起）。默认值没有改，要改需走弃用流程（Track A 05 号模块读的是哪一个，先查 `tests/r_parity/05_sunab.py`）。
- **anticipation**：`sun_abraham(anticipation=k)` 等于 fixest `sunab(ref.p = -1-k)`，相对时间 `-k..-1` 作为预期效应估计和报告，不进前趋势检验、不进事后平均（与 CS 的 `anticipation` 同义）。`did_imputation(shift=k)` 跟 Stata `shift()`：处理日期整体前移 k 期，horizon 从**前移后的**日期起算，总体 ATT 包含预期期。两者语义不同是因为各自跟随自己的参照实现；`gardner_did` / `stacked_did` / `etwfe` 尚无 anticipation 参数，等价做法是传入 `g - k` 的 cohort 列。
- **`sp.did_imputation` 的 BJS 前期系数（2026-10-19 起）**：领先项来自未处理样本上的辅助回归，处理后各期来自插补，两者都是结果变量的线性函数，交叉协方差就是两组按聚类求和的得分之积再求和——Stata `did_imputation` 的 `e(V)` 正是这样 `matrix accum` 出来的。领先项得分在 `_bjs_pretrends.py` 里随 `frame.attrs['scores']` 返回，`did_imputation` 把它与各期得分并排后取 `S'S`。领先项的 dof 调整跟 `reghdfe`：先迭代剔除单位或时期的单例（只有一个未处理期的单位），再数 `N` 和 `G`；单例自己拟合自己的固定效应，系数和 meat 都不变。证据：`tests/reference_parity/test_did_imputation_pretrend_vcov_Stata_parity.py`。
- **Honest DiD 的顶点枚举（`did/_arp.py::_square_basis_vertices`）**：对偶多面体的全部基一次批量求解；行列式下界 `|det|/F^(q-1) > F q eps` 能判定满秩的基不做 SVD，其余才用与 `matrix_rank` 相同的阈值。判定与原来逐基循环一致，改这段时跑 `tests/reference_parity/test_honest_rm_R_parity.py`（Conditional 必须逐点相同）。
- **Honest DiD 的限制族（`did/_honest_sets.py`，2026-10-19 起）**：`sp.honest_did(bias_direction=, monotonicity_direction=)` 与 `method='smoothness_relative_magnitude'`（Δ^SDRM）全部原生实现，矩阵逐行照 HonestDiD 0.2.8 的 `.create_A_*`，网格照它的布局：平滑族 Conditional / C-LF 用 `beta = 0` 处的识别集 ±20 sd，C-F 用 `alpha/10` 的 FLCI（C-F 的集合必在其中，所以不扩展网格），相对幅度族 ±20 sd。与 R 的三处有意不同或须知：(1) 只有一个前期时 `.create_A_M` 在 R 里循环 `1:0`，把 `δ_{-2} ≤ 0` 写成了 `δ_{-2} ≤ δ_0`（更弱），我们用定义本身的行；(2) 负偏向、多后期时 R 把识别集取反（只影响网格位置），我们照抄以保证逐点相同，网格不够时由扩展补；(3) C-F 的 `vbar` 用最小二乘解而不是 CVXR，检验只通过 `A' vbar` 依赖它，所有极小点相同。Conditional 与 R 逐点相同（T2），C-F 在一个网格步内（FLCI 中心两边只对到 1e-5，T4），C-LF 是随机筛查（S）。证据：`tests/reference_parity/test_honest_restrictions_R_parity.py`，fixture 分成多次短的 R 运行（`_fixtures/_generate_honest_restrictions_R.sh`）。
- **`sp.breakdown_m` 的限制族（`did/_honest_breakdown.py`，2026-10-20 起）**：除平滑族的 FLCI 默认路径外（相对幅度族的 C-LF 默认路径 2026-10-20 起也改用下述扫描，见下一句），`bias_direction` / `monotonicity_direction` / `method='smoothness_relative_magnitude'` / 平滑族的检验反演区间都取 `sp.honest_did` 报告的同一个集合，breakdown 是**集合第一次包含 0 的 M**。这些集合对 M **不嵌套**（R `HonestDiD` 自己的 `Delta^RMNB` 在 0.0026 含 0、0.0052 不含、0.01 又含），所以不能用倍增区间二分：`_first_inclusion` 在对数网格（每倍频 4 点，从 `unit/1024` 到 `1e4 unit`）上向上扫描，找到第一个含 0 的区间再二分到相对 1e-3；比网格步长更窄的提前含 0 区间看不到。空集（前期系数在该 M 下拒绝限制）算作不含 0、继续扫描并告警。R 证据：Conditional 网格在 `0.997 M*` 不含 0、`1.003 M*` 含 0（`tests/reference_parity/test_honest_breakdown_R_parity.py`，十种限制）。相对幅度族默认的 C-LF 路径（`_breakdown_rm`）同样用 `_first_inclusion`（以前是倍增区间二分到绝对 1e-3，数值在第三、四位变动）；C-LF 两边都是模拟的临界值，R 证据是括号式的筛查：HonestDiD 的 C-LF 表在 `0.97 M*` 不含 0、`1.03 M*` 含 0，六个案例（`test_honest_breakdown_rm_clf_R.py`）。空集在这条路径上仍按 `honest_did` 的 `rejects_zero` 口径算作含 0。同一轮修了平滑族 Conditional / C-LF 的默认网格：估计值离 0 超过识别集半宽 + 20 sd 时网格不覆盖它、返回空集（R 返回 NA），现在与相对幅度族一样移到估计值两侧。
- **`did/honest_did.py` 与 `did/_arp.py` 的拆分（2026-10-20）**：`honest_did.py` 只留 `honest_did` 与原生表；参数检查 / 网格 / 事件研究抽取器在 `_honest_common.py`，R 后端在 `_honest_r.py`（测试里 monkeypatch `_find_rscript` 要打在这个模块上），`breakdown_m` 在 `_honest_breakdown.py`，矩接口在 `_honest_moments.py`（它在函数内 import `honest_did`，避免循环）；`_arp.py` 留矩阵 / 线性规划 / 检验，网格反演在 `_arp_sets.py`，`_arp` 用模块级 `__getattr__` 转发 `rm_confidence_set` / `union_confidence_set`（`_MAX_BASES` 仍在 `_arp`，monkeypatch 照旧有效）。

在只有部分对照违规时也保留全部原对照（全数据 lag=2、lead 0:2 的 52.12），我们照规则剔除；(2) 安慰剂 t-k 的估计对处理时点距面板末期不足 k-2 期的集合，R 丢掉 `Y[t-1]` 项，我们不丢；(3) ATC 的倾向得分加权：被匹配的观测 d=0、对照 d=1，要让对照像被匹配的观测，权重应是“是被匹配观测”的 odds（我们），R 用的是其倒数，夹具 `atc_ps` 上把 x1 在 t 期的标准化差从 −0.82 拉到 −1.28，我们的是 −0.35；ATE 的 ATC 一半随之不同；(4) `ps_match` 里 R 把与处理观测得分**完全相同**的对照排除（集合不超过 `size_match` 时也排除，只剩一个对照时除外，全部相同时给全零权重），我们保留（夹具 `psm_ties`，协变量为 region）；(5) CBPS bootstrap 给 pooled，这一项是我们的扩展。`model_info['propensity_scores']` 给出倾向精炼用到的每个 (单位, 期) 的得分。没有实现：`ps.msm.weight` / `CBPS.msm.weight`、`listwise.delete`、`matching=FALSE`、`moderator`。**共同时间冲击（2026-10-20 - **`sp.didregress(aggregate=)`（`did/_did_aggregate.py`，2026-10-19 起）**：Stata 18 `didregress` / `xtdidregress` 的 `aggregate(standard | dlang | dlang, varying)`。第一步只去掉**在某个组×期格内取值变化**的协变量（格固定效应下一个共同斜率，`dlang_varying` 每格单独回归取截距），面板也只吸收格效应、不吸收个体效应（与 Stata 一致）；格内恒定的协变量进第二步。第二步在格上回归处理、格级协变量与组和期效应：`dlang` 用 OLS 方差，`standard` 按组聚类（小样本因子把组效应计入 K，与原 didregress 同）。估计与 SE 在 10 组设置上与 Stata 对到 1e-10（`tests/reference_parity/test_didregress_dlang_stata.py`）。**有意的不同**：Stata 的 dlang t 参照自由度是 `格数 − (回归元 + 期数)`，**漏掉了被吸收的组效应**；正态误差下 OLS t 统计量的精确分布是 `格数 − 全部参数`，这是默认（`dlang_df='residual'`），`dlang_df='stata'` 复现 Stata 的区间。**Stata 的一个坑**：它判断协变量是否格内恒定用的是浮点比较，`set type double` 读入非二进制有限小数的格级协变量时会判成格内变化、随后被格效应吸收、**无提示地从模型里消失**（夹具里的 `z` 因此取 1/16 的倍数，两种存储下都恒定）；我们用精确相等判定。`dlang_varying` 的格若观测数不超过参数个数，Stata 照样给数（`regress` 丢掉共线列后取截距），我们拒绝。

- **`sp.bacon_decomposition(covariates=)`（`did/_bacon_controls.py`，2026-10-19 起）**：带控制变量的 Goodman-Bacon 分解（2021 第 5 节），逐项跟 R `bacondecomp` 0.1.1（MIT，读过源码）：处理对控制变量与双向效应做 FWL，残差的组内部分给 `beta_within` 与 `omega`，组间每一对（只取较早组对较晚组，每对一次）合成 2x2 项与控制变量组-期均值项。平衡面板上所有带双向效应的回归都用精确的双重去均值。**always-treated 对 never-treated 这一对没有 2x2 变异**：R 里 `VD` 是舍入噪声、R² 由噪声回归得到，但都乘以 ~0，权重与估计只剩控制变量均值项；我们把 `VD < 1e-12` 判为零、直接取该项，与 R 对到 1e-10（该对的 `beta_2x2` 报 NaN）。恒等式 `TWFE = omega·beta_within + (1-omega)·Σ weight·estimate` 精确成立（1e-12）。不带 `covariates` 时代码路径与数字都没变（Track A 20 重跑逐字节相同）。
- **`sp.xtevent(trend=, proxy=)`（`did/_xtevent_ext.py`，2026-10-19 起）**：Stata `xtevent` 3.1.0 的 `trend()` 与 `proxy()` / `proxyiv()`，在 11 组设置上逐项对到 1e-9（`tests/reference_parity/test_xtevent_extensions_Stata_parity.py`）。`trend_method='gmm'`（Stata 默认）用 `trend..-2` 系数的逆协方差做最小距离拟合过 -1 处零点的直线并调整全部系数与协方差；`'ols'` 去掉这些事件时间虚拟变量、加入窗口内的事件时间（窗口外与从未处理为 0），只接受一次性采纳的 0/1 政策。代理变量 IV 是 `xtivreg, fe`：单位效应去均值、期虚拟变量作外生回归元，iid 方差除以 `N − 单位数 − K`，聚类乘 `G/(G−1)·(N−1)/(N−K−1)`（K 含常数），正态参照；`vce='robust'` 按 Stata 变成按单位聚类。归一化规则：领先 v 作工具时其系数（-v）归零，-v 等于 `norm` 时改归零 -v-1；每个外部工具归零一个离零最近的可用前期；代理个数等于归零个数时再加一个。`'select'` 取对代理回归 F 最大的领先。二值一次性采纳的政策上，排除 -1 与 -2 后用 Δz 的第 1 或第 2 个领先作工具结果相同（两者在其余回归元张成的空间外只差符号）。**有意的不同**：`trend` 晚于窗口起点时，Stata 调整后的协方差把趋势权重放在窗口起点的系数上（点估计正确），我们按 delta 方法放在拟合趋势所用的系数上；测试同时用错位权重逐位复现 Stata 的 SE。trend 下 Stata 的 `diffavg` 去掉端点，我们未实现，返回 unavailable。最平滑路径见下一条 `sp.xtevent_smpath`。
- **`sp.xtevent_smpath`（`did/_xtevent_smpath.py`，2026-10-20 起）**：Stata `xteventplot, smpath(line)` 的"最不弯曲"路径（Freyaldenhoven-Hansen-Pérez Pérez-Shapiro 的 Suggestion 6）：在过归一化系数（=0）的多项式里取 Wald 区域内**次数最低**的，同次数里取**首项系数绝对值最小**的。两步都是闭式解：在"在归一化时点为 0"的子空间上 Wald 统计量是二次型，`q_min(p)` 逐次计算（即 Stata 打印的 "Order k / Wald value"，`attrs['wald_by_order']`，与 Stata 显示的 9 位有效数字一致），首项系数在椭球上取值区间离 0 最近的端点由切点给出。Stata 用 `nr 5 bfgs` 数值优化、帮助文件自称近似解，所以路径只做 S 级筛查（四个设定 1e-7、一个聚类设定 2e-4，后者我们的首项系数更小、仍在区域内）。约定都照 Stata（黑盒对出来）：`maxorder` 是**次数**（Order 0 是常数，归一化后就是零路径），Wald 区域含端点系数，卡方临界值自由度 = 区域内系数个数，`postwindow=k` 只让事后 `0..k-1` 进区域（Stata 只在这些时点画线，我们在整个窗口上给出路径值）。不接受 `trend=` / `proxy=` 的拟合。xtevent 的许可证在包里没写，按黑盒处理：只读了帮助文件和论文（NBER WP 29170 第 2.6 节）。证据：`tests/reference_parity/test_xtevent_smpath_Stata_screen.py`（fixture 由 `_generate_xtevent_smpath_Stata.do` 从图的 serset 和日志里读回）。
