# 工具变量与 MTE

> 从 CLAUDE.md §11 原样迁来（2026-10-17）。改动本领域的代码前先读完本文件；新的约定直接写在这里，CLAUDE.md §11 只留索引。

- **`regression/iv.py`**：投影走 QR、2SLS 第二阶段走 `lstsq`，不要改回 `(W'W)^-1` / `(X'PX)^-1`（条件数平方两次，立方工具变量设计上丢 7 位）。与外生回归元和其它工具变量共线的排除工具变量由 `_independent_instruments` 丢弃并告警（`model_info['omitted_instruments']`），不再抛 numpy 的 `Singular matrix`。稳健 2SLS 之后 `sp.estat(result, 'overid')` 的 Hansen J 同时就是 Stata `estat overid` 的稳健 score 统计量（键 `score`）；`iid_errors` 里是 Sargan / Basmann（LIML 为 Anderson-Rubin / Basmann F）。Stata 在 `ivregress, perfect` 下的 score 统计量随工具变量书写顺序变化，那是参考实现的问题，不要去对它。
- **`iv/mte.py`**：ATT / ATU 是系数的精确线性函数（`_aggregate_functionals`）：处理组是 `U < P` 的单位，所以对**全样本**按 `p_i` 加权积分 `∫_0^{p_i} MTE`，不是用处理组内的倾向得分分布（2026-10 前的做法，线性 MTE 下 ATT 1.22 对真值 1.30）。聚合量与曲线的标准误必须用系数的**完整**协方差（多项式各项系数强负相关，只取对角会把 ATE 标准误夸大三倍），解析标准误以拟合的倾向得分和协变量为条件，`bootstrap=` 才包含两者。bootstrap 必须重抽**修剪前**的数据并在每次抽样里重做修剪。
- **弱工具变量稳健检验的两种口径（`sp.weakrobust`，2026-10-19 起）。** 单个内生变量、不给 `cluster` / `test_vcov` / `subset` / `project` 时沿用 R `ivmodel` 口径（AR 为 F 统计量，`convention == 'ivmodel'`），数值不变。其余情形走 Stata `weakiv` 的 LM 口径（`diagnostics/_weakiv_lm.py`，`convention == 'weakiv'`）：AR / K / J / rk / CLR 在 iid、robust、cluster 下与 weakiv 2.4.07 对到 1e-12（`tests/reference_parity/test_weakiv_stata.py`）。三处**有意不跟** weakiv：(1) CLR p 值用精确的条件积分；weakiv 单内生变量用 20 节点 Simpson（差 ~1e-7，测试里复现了它的 `new_try`），多内生变量时它把 AR 与 K 当独立卡方模拟，而 AR = K + J，分布不同（同一数据 0.80 对 0.75），我们不复制；(2) 单内生变量的集合精确反演所报告的 LM 检验；weakiv 的 iid 闭式 AR / K 区间反演的是 Wald 形式，它自己的 AR p 值在其端点处是 0.053；(3) `project=` 在整条实轴上取最小（LIML 根的闭式），weakiv 只在用户给的格点范围内搜索，范围外的最小值它看不到，集合因而偏窄。`subset=` / `project=` 只在 iid 下提供（与 weakiv 的 subset 相同）；robust / cluster 下拒绝而不是数值寻优。`sp.anderson_rubin_test(endog=[...])` 是联合 AR F 检验，`h0 = 0` 时即 `ivreg2` 的 `e(arf)`（`test_hdfe_iv_ivreghdfe.py` 用 ivreghdfe 对过）。
- **`panel/_hdfe_iv.py` 的秩统计量（2026-10-19 起）。** 多个内生变量时 KP rk Wald F / underid LM / Cragg-Donald F 走 `sp.kleibergen_paap_rk`（`ranktest` 的 SVD 构造），`n_absorbed = k_exog + sdof`，与 ivreghdfe 的 `e(rkf)` / `e(idstat)` / `e(cdf)` 对到 1e-9；此前为 NaN。
- **多工具变量标准误（`sp.liml(robust='many_weak')`，`regression/_many_iv_se.py`，2026-10-20 起）**：Hansen-Hausman-Newey（2008）第 2 节的方差，Bekker（1994）项加上非正态误差的三阶、四阶矩项（`A`、`B`），LIML 与 Fuller 都适用。`p_tt` 是**工具变量**投影 `P_Z`（含被包含的外生变量）的对角元，`K` 是全部工具个数，`X` 含全部回归元；与把外生变量先剔除后的写法逐位相同（测试守着）。R `ivmodel` 1.9.1 的 `manyweakSE=TRUE` 与此不同（T4，**不复制**）：它的数等于同一公式在剔除外生变量后的数据上、改用回归元 `[D, X]` 投影的对角元、`K` 取被排除工具个数、`s2 = u'u/(n - 1 - ncol(X))` 的结果，对到 1e-10（`tests/test_liml_many_weak_se.py`，夹具 `tests/fixtures/many_iv/`，ivmodel 是 GPL-2，只用输出）。点估计与经典标准误与 ivmodel 相同。证据另有模拟：K = 100、n = 500、偏态同方差误差，1000 次重复覆盖率 0.953（经典 SE 0.864）。这个公式要求同方差；异方差下的多工具推断（Chao 等 2012）没做。
- **`rlasso/iv.py`（`sp.rlasso_iv`）与 hdm 0.3.2 的四处有意不同（2026-10-21 起，第 (4) 条 2026-10-22）。** hdm 是 MIT，源码可读。(1) `select_Z=True, select_X=False`：第一阶段带截距，第二阶段也必须带；`rlassoIVselectZ` 不带，y 或 d 均值非零时斜率不一致（已知真值 -2 的 DGP 上 hdm 给 -0.65）。常数和控制变量一起用列主元 QR 偏出（Frisch-Waugh），重复的常数列被 QR 丢掉。所有工具都被选中且无控制变量时，结果就是稳健 2SLS（测试断言与 `sp.ivreg(robust='hc0')` 一致到 1e-10）。(2) 同一路径的方差是 `A^{-1} Ω A^{-1}'`（`A` 为偏出控制变量后的 `Dhat_r' d_r`）；hdm 用 `ginv(t(d) %*% Dhat)` 即 `A^+'`，第一阶段漏选某个控制变量时 `A` 不对称，SE 就错（蒙特卡洛：实际 SD 0.239，正确公式 0.234，hdm 公式 0.363）；hdm 自己的 `tsls(homoscedastic=FALSE)` 给的是正确值，参照夹具就用它。(3) 双重选择里 PZ 对 x 什么都没选时，工具按 `mean(PZ)` 中心化；hdm 用 `mean(x)`（整个控制矩阵的均值），斜率不变但稳健 SE 被放大。`intercept=` 现在传到所有路径的 rlasso（以前只传到 select_Z 路径）。(4) 同一路径第二阶段精确求解，不用 `ginv`（2026-10-22）。hdm 对 `t(Dhat) %*% cbind(d, x)` 取 `MASS::ginv`，这个矩阵把控制变量的条件数平方：EminentDomain 的 80 个控制变量满秩（条件数 7e6），乘积的条件数 5e13，`sqrt(eps)` 截断丢掉 81 个奇异值里的 34 个，hdm 打印的 0.2274 是截断 SVD 的值，随容差乱跳（1e-10 给 0.0054、1e-12 给 0.0212）。现在偏出控制变量后解 ke×ke 系统，EminentDomain logGDP 为 0.0154（HC0 SE 0.0141），参照是 `AER::ivreg` + `sandwich::vcovHC(type="HC0")`，差 6e-13。**不要回到 `ginv` 去"对齐 hdm"**：那是对齐一个随容差变化的数。旧的 `iv.bch_post_lasso_iv` 在这里给 0.0130，"差 17 倍"的说法是拿截断值比出来的，已从弃用提示和文档中删掉。hdm 的原值保留在夹具 `selectZ_hdm_raw` 里，不要改回去。
- **GMM 的 `small` 与权重矩阵（2026-10-23 起）。** `_gmm_fit` 的有限样本因子在所有不聚类的权重矩阵下都是 `n/(n-k)`，聚类时 `G/(G-1)·(n-1)/(n-k)`；`small=False`（`_ivregress_large_sample`）再把它除掉。1.40.1 及以前未调整权重矩阵（默认 `robust='nonrobust'`）这一支是 1，于是 `small=True` 报的是大样本方差配 t / F，`ivregress gmm, wmatrix(unadjusted) [vce(robust)] small` 没有对应（外部审计发现，⚠️）。现在映射是：默认 = `wmatrix(unadjusted) vce(robust) small`，`gmm_vcov='efficient'` = `wmatrix(unadjusted) small`，各加 `small=False` 去掉 `small`。注意 GMM 里 `robust=` / `cluster=` 选的是**权重矩阵**，方差由 `gmm_vcov` 决定，所以 `robust='nonrobust'` 的默认报的是 sandwich（`model_info['gmm_vcov']` / `['gmm_wmatrix']`，`inference_rule()['vcov']` 按方差命名）。不要把这个因子推广到 Hansen J（J 不随 `small` 变，测试守着）。证据：`tests/reference_parity/test_iv_gmm_stata_parity.py`（Card）、`test_inference_conventions_stata_parity.py`（审计数据）。
- **GMM 的 `wmatrix=` 与 1.42 默认（2026-10-24 用户授权决定）。** `wmatrix=` 单独指定权重矩阵（`robust` / `unadjusted` / `cluster`），`cluster=` 单独指定方差，所以 `wmatrix(robust) vce(cluster g)`、`wmatrix(unadjusted) vce(cluster g)` 现在都有对应（对 Stata 18 到 1e-15）。不写 `wmatrix=` 时（`_resolve_gmm_wmatrix`）：有 `cluster=` 用 `cluster`，否则 **1.42 起一律 `robust`**（Stata `ivregress gmm`、linearmodels `IVGMM` 的默认；1.41 及以前过度识别且无稳健方差时是 `unadjusted` 即 2SLS，那一版发 FutureWarning）。恰好识别仍走 `unadjusted`：权重矩阵不影响估计量与 sandwich，数字与旧版逐位相同。默认调用对 Stata `ivregress gmm` 默认到 5e-9（`test_iv_gmm_stata_parity.py::test_default_is_ivregress_gmm_wmatrix_robust`）。`sp.iv` 的 `small=True` 默认**不改**：R `AER::ivreg`、`fixest`、`ivreg2, small`、`sp.ivreg` 都是小样本口径，只有 `ivregress` 默认大样本；靠 `inference_rule()` 和翻译器解决，不要再提议翻转。
- **`iv/recentered.py`（`sp.recentered_iv`，Borusyak-Hull 2023，2026-10-28 起）。** 期望工具变量 `mu` 是用户给的 S 个反事实冲击下工具变量的逐行均值，**不含**实现的那一次（论文 (8) 式用随机置换近似；用户若枚举了整个置换类，把实现的那次也作为一列传进来即可）。`method='recenter'` 用 `z - mu` 做工具（论文表 1 第 2 列）；`method='control'` 用 `z` 做工具并控制 `mu`（第 3 列）。处理变量就是暴露本身时，前者是 `z` 被 `z - mu` 工具化的 IV，**不是** `y` 对 `z - mu` 的 OLS（两者只在样本里 `sum (z - mu) mu = 0` 时相同）；后者是 `y` 对 `z`、`mu` 的 OLS。点估计和渐近推断直接调 `sp.iv` / `sp.regress`，不在本文件里重写 sandwich。
- **RI 的参照集**是实现的那次加 S 个反事实，全部以它们的共同均值 `(z + sum_s z_s)/(S+1)` 中心化，y、x 先对截距和控制变量（`control` 时再加 `mu`）做加权残差化。这样 `recenter` 下检验在可交换抽样下精确，且检验的 Hodges-Lehmann 估计量（`T(b) = 0` 的根）恰好等于报告的点估计（论文 Lemma 2；测试断言到 1e-9）。不要改成只用 S 个反事实的均值中心化，那样两条性质都丢。`control` 下 `mu` 不含实现的那次，精确性只在 S 增大时成立，文档已写明。
- **置信集是精确反演**（`_ri_confidence_set`）：每个抽样 s 拒绝 b 的条件是一个二次不等式，把所有根排序扫一遍得到分段常数的计数，不用格点。集合可以无界或不连通；无界时发 `AssumptionWarning`。论文脚注 27 说明了不能用重抽样下估计量的分布做区间（重抽的工具第一阶段为零）。
- **`recenter` 在处理变量就是暴露、且 `mu` 解释了暴露大部分方差时，RI 功效很低**：重抽工具与固定不动的处理变量里随 `mu` 变化的部分相关，`c_s` 的离散度很大，集合常常无界，而渐近 F 可以很大（同一组数据 F = 84、RI 集合无界）。这不是 bug，是论文说控制 `mu` 能提高精度的原因；这时用 `method='control'` 或加入能吸收 `mu` 的控制变量。
- 未决：论文的 Conley 空间标准误（表 1 括号里那组）没有接；有效工具变量（第 3.5 节，需要 `E[x|g,w]` 和 `E[εε'|w]` 的模型）没做；论文的高铁与 Medicaid 两个应用没有复现（要新数据，不在本轮范围）。
- **`panel/_iv_sw.py`：Sanderson-Windmeijer 条件第一阶段（2026-10-28 起）。** 两个及以上内生变量时，`iv_diagnostics['first_stage'][name]` 给出 `sw_F` / `sw_chi2` / `sw_partial_r2`，iid、robust、cluster 三种方差下与 `ivreg2` / `ivreghdfe ..., first` 的 `e(first)` 对到 6e-10（`tests/reference_parity/test_iv_sw_first_stage_parity.py`）。一个内生变量时 SW 就是普通第一阶段 F。`sp.iv` 的增广诊断 "SW conditional F (name)" 2026-10-28 起也走 `sw_first_stage`：稳健 / 一维聚类拟合报对应方差下的 SW F（ivreg2 4.1.12 的 robust / cluster 值，`tests/test_iv_scan3_weak.py` 到 1e-9），`absorb=` 下把吸收的固定效应计入残差自由度（此前 iid 下比 ivreghdfe 高 13%）；`tests/reference_parity/test_iv_sw_first_stage_parity.py::test_sp_iv_matches_ivreg2_first` 覆盖 14 个格。多维聚类没有参考，仍报经典 F，`diagnostics["SW conditional F cov type"]` 写明。
- **`mediation/iv_mediate.py`（`sp.iv_mediate`，2026-10-28 起）。** Dippel、Ferrara、Heblich 的 IV 中介（`dippel2020causal`），与 Stata `ivmediate` 1.0.4 对到 1.6e-11。和 ivmediate 一样只接受一个工具变量、一个吸收因子；中介变量是处理与控制变量的线性函数时抛 `IdentificationFailure`，第一阶段 F < 10 发 `AssumptionWarning`。
- **`sp.expected_instrument` 与 `sp.recentered_iv(absorb=, expected=)` 的分工（`iv/expected_instrument.py`，2026-10-28 起）。** 同一天两条线各写了一个 Borusyak-Hull 估计器，保留的是上面 `iv/recentered.py` 那一个；另一条线的估计器已删除，只留下它的模拟器和两个新参数。(1) `sp.expected_instrument(data, instrument_fn, shock_sampler, ...)` **只做模拟**：按已知的冲击分配过程（自定义 callable，或内置的 `{'kind': 'bernoulli'}` / `{'kind': 'permute', 'strata': ...}`）重抽冲击、重建工具，返回 `mu`、蒙特卡洛 SE，以及 `(n, n_draws)` 的 `draws`（`counterfactual()` 给出同一矩阵的 DataFrame，索引对齐 `data`）。`draws` 就是 `sp.recentered_iv(counterfactual=...)` 要的输入，无暴露的行为 NaN，到那边会告警删除。**不要**把同一次调用的 `ei.mu` 再作为 `expected=` 和它的 `ei.draws` 一起传：`mu` 依赖于与之比较的抽样，精确性就丢了；要用模拟的固定 `mu`，用两个不同种子各调一次。(2) `absorb=`：点估计与 SE 走 `sp.iv(absorb=)`（ivreghdfe 口径：剔除 singleton，嵌套在聚类里的 FE 不扣自由度）；处理变量就是暴露时的 OLS 支路用“自己做自己的工具”的 2SLS（`sp.regress` 没有 `absorb=`，二者估计量、sandwich 与自由度都相同，测试对 FE 哑变量版本断言到 1e-10）。RI 统计量按 FWL 先用 `sp.fast.demean`（tol 1e-13，不剔 singleton，singleton 的组内值为零、对内积无贡献）扫掉 FE，再对扫过的控制变量做投影，所以 Hodges-Lehmann 根仍等于点估计。`mu` 在 FE 内为常数时视同被吸收（告警，两种方法都等于未调整估计）；`z - mu` 在 FE 内无变化时抛 `AssumptionViolation`；与 `weights=` 同用时报错（`sp.iv` 的吸收路径没有加权扫除）。(3) `expected=`：闭式 `mu`（列名或长度 n 的数组）代替抽样的行均值；RI 里实现的那次和每个反事实都以这个固定的 `mu` 中心化，`mu` 不依赖抽样，所以对两种方法、任意 S 都精确。它是与 Stata `ritest` 逐一对齐的必要条件：`ritest` 的 `T = zs' M (y - b0 d)` 中 `M` 扫掉了层，等价于以层均值（层内置换下的精确 `mu`）中心化；默认的共同均值中心化在 `b0 = 1.2` 处统计量差 `mu_all' M e = 1.53`，计数是 150 而不是 146，是另一个同样精确的检验，不是 bug，测试钉住了这个恒等式。不传 `absorb` / `expected` 时输出与改动前逐位一致（96 组配置、1,800 个浮点数），只多一个诊断键 `ri_statistic`（观测统计量 `a - ri_null * c`）。证据：`tests/reference_parity/test_recentered_iv_stata.py` 对 `ivreghdfe` 1.1.4（`absorb(f)`，聚类与 HC1，recenter / control / naive）差 ≤ 3e-15，对 `ritest` 1.1.7 的 200 个固定置换（`samplingsourcefile`，确定性比较）计数 0 与 146 逐一相同、观测统计量相对差 5.6e-15；置换文件以 `recentered_iv_ri_perms.csv.gz` 存放（明文 543 KB 超过 500 KB 的提交上限，do 文件先解压到临时文件）。`tests/test_expected_instrument.py`：伯努利份额工具的闭式收敛（按 `1/sqrt(S)`）、公平硬币下 `mu` 为常数、层内置换的层均值、可复现与行序、流式矩、把 `draws` 喂给 `recentered_iv` 回收已知真值（朴素 IV 偏差 > 0.3）。
- **`vce='conley'` 与有效工具（2026-10-28 后续一轮）。** `vce='conley'` 是对主回归与未调整回归各调一次 `sp.conley`（`conley_kernel` / `conley_distance` 原样转交），不在本文件重写 sandwich；`absorb` 时用 `sp.iv` 同一规则（`fast.demean(drop_singletons=True)`）算出保留行再取坐标；与 `cluster=`、`weights=` 互斥（`sp.conley` 不做加权 2SLS）。测试：对 `sp.conley(sp.iv(...))` 1e-10、对稠密手算 1e-9、planar + uniform 对 acreg 钉住的 `sp.ivreg(vce='conley')` 1e-10。论文本身提醒共同暴露会让得分的相关超出任何距离截断，RI 不依赖截断。`resid_var=` / `resid_mean=` 是工作论文（NBER WP 27845，2021 修订版，第 3.5 节式 (9) 与引理 3）的有效工具 `(Omega + psi psi')^{-1}(z - mu)`，用 Sherman-Morrison 按 `Omega^{-1}(z~ - nu rho psi)` 计算，**发表版 Econometrica 正文没有这一节**（只引用工作论文），所以引用 `borusyak2020nonrandom`。映射只依赖 `w`、线性，RI 对每一次抽样做同一变换，仍精确，Hodges-Lehmann 根仍等于点估计；balance 检验仍用未变换的 `z - mu`。论文的第 1、2 步（用冲击预测处理并重新中心化）就是把预测处理作为 `exposure` 连同其反事实抽样传入，不另设参数；只对 `method='recenter'` 定义。默认输出 8 组配置逐字节不变。已知真值模拟（150 次）：方差比 0.84（仅 `resid_var`）与 0.58（两者）。未做：非对角 Omega、Omega / psi 的可行估计（论文未给）、加权或聚类下的 Conley。
- **`panel/_hdfe_iv.py` 的 `sdofminus`（2026-10-28 起）。** 所有吸收的固定效应都嵌套在聚类变量里时，reghdfe 的 `e(df_a) = 0`，ivreghdfe 仍为被扫掉的常数收 1 个自由度：`e(sdofminus) = 1`。1.41 及以前我们收 0，聚类 SE 偏小约 1/(2N)（N = 785 时 6.4e-4；500 万行时 1e-7，fixest 与 ivreghdfe 彼此一致而与我们差这一个自由度）。现为 `max(dof_fe_cl - 1, 1)`；部分嵌套（`firm + city^q`，`sdofminus = df_a = 41`）本来就对。证据 `tests/reference_parity/test_hdfe_iv_nested_sdof.py`（Stata 18，四种吸收设定，含一阶段 / KP / CD / J）。同一轮的提速（`_codes_nested_in_cluster` 向量化、`_meat` 用 `bincount` 且聚类只因子化一次、`demean(copy=False)`）逐位不变。

- **`resid_cov=`（非对角 Omega，2026-10-28 补完）。** 两种输入：稠密 n×n 协方差（按估计行取子矩阵，因缺失被删的行连同其行列一并去掉；此时不得再给 `resid_var`，对角已在矩阵里）；或 `{'cluster': col, 'rho': r}`，簇内等相关，`Omega_ij = r sqrt(v_i v_j)`，对角取 `resid_var`。代码在 `iv/_recentered_omega.py`：稠密用 Cholesky（对称性相对 1e-10、有限、正定逐一检查，失败抛 `MethodIncompatibility`）；簇内等相关按 `S^{-1}(u - c 1 1'u)/(1-rho)`（`c = rho/(1 - rho + m rho)`）闭式求解，不建 n×n 矩阵，要求每个簇 `-1/(m-1) < rho < 1`。`resid_mean` 的 ψψ′ 项仍按 Sherman-Morrison 加上。映射线性且只依赖 `w`，RI 对每次抽样做同一变换，仍精确，Hodges-Lehmann 根等于点估计（含 `absorb`）。证据 T1：对稠密求解 1e-10；等相关形式等于它所描述的稠密矩阵 1e-10；`diag(v)` 与 `rho = 0` 都退回 `resid_var` 路径 1e-12；簇内相关 0.6 的已知真值模拟（150 次）中，等相关工具对对角工具的方差比 0.42。默认输出 16 组配置逐字节不变。仍未做：每簇不同 rho、一般分块、Omega / psi / rho 的可行估计（论文未给）；稠密形式 O(n³)，只适合中等 n。
